# 同一个问题，大模型回答不一致
> Last Format Time：10/8/2026 23:35:46

Token（词元）：模型处理文本时使用的基本单位，可以是一个词、一个词的一部分或其他文本片段。

概率分布（Probability Distribution）：模型生成文本时，会给候选下一个 Token 分配概率。

例如模型要生成一句话：

输入：“React 是一个……”

假设性的下一 Token 候选概率

这些数字只是为了说明机制。

模型会依据预测概率和解码策略选择后续 Token，而新的 Token 又会影响再下一步的生成。

主要原因包括：

- 采样策略：temperature、top-p 等参数影响候选 Token 的选择。
- 上下文变化：历史对话、系统指令、检索文档不同，输出也可能不同。
- 运行时非确定性：即使降低随机性，在某些推理服务和计算环境中，也不保证每次输出完全相同。

需要纠正一个容易出现的说法：

> 不是因为模型“随机乱说”，而是生成过程以条件概率预测为基础，解码策略和实际上下文共同影响最终答案。
