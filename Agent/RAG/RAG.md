# RAG
> Last Format Time：10/8/2026 23:35:46

**R**etrieval-**A**ugmented **G**eneration，即检索增强生成

模型本身不一定知道企业最新知识、私有文档或实时业务数据，因此我们可以先检索外部知识，再把检索结果交给模型辅助生成回答

---
## 流程

- 用户提问，转为向量（Embedding）
- 去向量数据库（Vector Database）中去检索（Retrieval），找到语义相近的文档
- 组装 Prompt 给 LLM
- LLM 生成回答

例如用户问「公司一年有几天年假」，即使文档标题是「员工带薪休假管理规定」，向量检索也可能找到它，因为它们在==语义上相关==

---
## 常见召回方式
|方式|原理|典型用途|
|---|---|---|
|关键词检索|BM25 等文本匹配算法|专业术语、精确名称、编号|
|向量检索|计算 Embedding 语义相似度|表述不同但语义相近的问题|
|混合检索|结合关键词与向量结果|同时兼顾精确匹配和语义匹配|
