这里的 `&` 是 TypeScript 的**交叉类型（Intersection Type）**，表示：

> 返回值必须同时满足 `AnatomyEntry` 和 `{ kind: "directory" }` 这两个类型。

```ts
AnatomyEntry & { kind: "directory" }
```

可以理解成：

```ts
AnatomyEntry
并且
kind 属性必须是 "directory"
```

## 为什么不直接写 `AnatomyEntry`

如果返回类型只写：

```ts
): AnatomyEntry {
```

TypeScript 只知道返回值是某一种 `AnatomyEntry`，但不一定知道它具体是目录节点。

例如：

```ts
const entry = createDirectoryEntry("src");
```

如果返回类型只是 `AnatomyEntry`，那么：

```ts
entry.kind;
```

可能被认为是：

```ts
"file" | "directory"
```

但实际上这个函数一定创建目录，所以更精确的返回类型应该告诉 TypeScript：

```ts
entry.kind; // 一定是 "directory"
```

因此写成：

```ts
): AnatomyEntry & { kind: "directory" }
```

## 举个简单例子

```ts
type Person = {
  name: string;
};

type Employee = Person & {
  employeeId: number;
};
```

`Employee` 必须同时拥有：

```ts
{
  name: string;
  employeeId: number;
}
```

例如：

```ts
const employee: Employee = {
  name: "Dano",
  employeeId: 1001,
};
```

缺少任意一部分都会报错：

```ts
const employee: Employee = {
  name: "Dano",
  // 缺少 employeeId，报错
};
```

你的代码也是类似的：

```ts
AnatomyEntry & {
  kind: "directory";
}
```

表示返回对象既要满足 `AnatomyEntry` 的全部要求，又要保证：

```ts
kind: "directory"
```

## 对调用方有什么好处

假设 `AnatomyEntry` 是一个联合类型：

```ts
type FileEntry = {
  kind: "file";
  name: string;
};

type DirectoryEntry = {
  kind: "directory";
  name: string;
  children: AnatomyNode[];
};

type AnatomyEntry = FileEntry | DirectoryEntry;
```

如果函数返回：

```ts
function createDirectoryEntry(): AnatomyEntry
```

调用后 TypeScript 只知道它是联合类型：

```ts
const entry = createDirectoryEntry();

entry.children;
// 可能报错，因为 FileEntry 没有 children
```

通常需要先判断：

```ts
if (entry.kind === "directory") {
  entry.children;
}
```

而如果明确返回：

```ts
function createDirectoryEntry():
  AnatomyEntry & { kind: "directory" }
```

TypeScript 就能确定它是目录类型：

```ts
const entry = createDirectoryEntry();

entry.children; // 可以直接访问
entry.kind;     // 类型为 "directory"
```

## `&` 和 `|` 的区别

```ts
A & B
```

表示同时满足 A 和 B：

```ts
type Result = {
  name: string;
} & {
  age: number;
};

// 必须同时有 name 和 age
```

而：

```ts
A | B
```

表示满足 A 或 B 中的任意一种：

```ts
type Result =
  | { kind: "file" }
  | { kind: "directory" };
```

所以可以简单记成：

```ts
&  // 并且
|  // 或者
```

你的返回类型：

```ts
AnatomyEntry & { kind: "directory" }
```

就是：

> 返回的是一个 `AnatomyEntry`，并且它明确是目录类型。

不过如果项目里已经单独定义了目录类型，更推荐直接写：

```ts
type DirectoryEntry = AnatomyEntry & {
  kind: "directory";
};
```

然后函数写成：

```ts
export const createDirectoryEntry = function (
  name: string,
  children: AnatomyNode[] = [],
  quantity?: (typeof AnatomyQuantityValues)[number],
): DirectoryEntry {
  // ...
};
```

这样语义会更清楚，也方便多处复用。
