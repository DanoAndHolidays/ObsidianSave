# 性能优化的一般流程 💡
> Last Format Time：10/8/2026 23:35:46

React Profiler、memo、Context 拆分、虚拟列表你已经学过

重要的是如何判断问题究竟发生在 React、JavaScript、浏览器渲染还是网络层，也就是位置


- 建议在面试中按照诊断链路回答：
	
	1. 先明确现象：首屏慢、输入卡顿、列表滚动掉帧，还是交互响应慢
	
	2. 使用浏览器 DevTools：Performance 查看主线程任务、脚本执行、Layout、Paint
	
	3. 定位 React 问题：Profiler 检查不必要渲染、长耗时组件
	
	4. 针对性优化：只有找到瓶颈后才考虑 memo、虚拟化、代码分割、缓存等方案
	
	5. 前后对比：使用一致的设备、数据和操作路径验证改进


不要把“使用 `useMemo`、`useCallback`”当成性能==排查流程==，这只是可能采用的优化手段
