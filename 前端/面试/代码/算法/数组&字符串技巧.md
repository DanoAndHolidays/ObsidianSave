# 数组&字符串技巧
> Last Format Time：6/25/2026 23:55:16

在 JavaScript 中，`split()` 和 `join()` 是两个非常常用且互为逆操作的方法。简单来说，`split()` 用于将字符串拆分为数组，而 `join()` 用于将数组拼接为字符串。

---
## String.prototype.split()
`split()` 方法用于将一个字符串按照指定的分隔符拆分成一个子字符串数组。它不会改变原始字符串。

**基本语法：**

```javascript
string.split(separator, limit)
```

- **separator（可选）**：指定分割点的字符串或正则表达式。如果省略，返回包含原字符串的数组；如果是空字符串 `""`，则按字符拆分。
- **limit（可选）**：限制返回的数组最大长度，超出部分会被丢弃。

**常见用法示例：**

```javascript
let str = "apple,banana,orange";

// 1. 基础用法：按逗号拆分
console.log(str.split(",")); 
// 输出: ["apple", "banana", "orange"]

// 2. 限制返回数组的长度
console.log(str.split(",", 2)); 
// 输出: ["apple", "banana"]

// 3. 高级用法：使用正则表达式（例如同时按逗号、分号、空格拆分）
let complexStr = "apple, banana; orange";
console.log(complexStr.split(/[,;\s]+/)); 
// 输出: ["apple", "banana", "orange"]
```

---
## Array.prototype.join()
`join()` 方法用于将数组中的所有元素连接成一个字符串。它同样不会改变原始数组。

**基本语法：**

```javascript
array.join(separator)
```

- **separator（可选）**：指定用来分隔每个元素的字符串。如果省略，默认使用逗号 `,` 作为分隔符；如果是空字符串 `""`，则无缝拼接。

**常见用法示例：**

```javascript
let arr = ["apple", "banana", "orange"];

// 1. 基础用法：默认用逗号拼接
console.log(arr.join()); 
// 输出: "apple,banana,orange"

// 2. 自定义分隔符
console.log(arr.join(" - ")); 
// 输出: "apple - banana - orange"

// 3. 无缝拼接（空字符串）
console.log(arr.join("")); 
// 输出: "applebananaorange"
```

## 进阶技巧与注意事项
**1. 组合使用实现字符串替换** 因为它们是互逆操作，经常结合使用来清洗或替换数据。例如，去除字符串中多余的空格：
```javascript
let messyStr = "  hello    world  ";
// 先按空格拆分，过滤掉空字符串，再按单个空格拼接回去
let cleanStr = messyStr.split(" ").filter(Boolean).join(" ");
console.log(cleanStr); // 输出: "hello world"
```

**2. 处理特殊值 (`null` / `undefined`)** 在使用 `join()` 时，如果数组中包含 `null` 或 `undefined`，它们会被转换为**空字符串**，而不是字面量的 `"null"` 或 `"undefined"`，这可能会产生连续的分隔符：
```javascript
let mixedArr = [1, undefined, null, 4];
console.log(mixedArr.join("-")); 
// 输出: "1---4" 
```

**3. 字符串转数字数组** 利用 `split()` 配合 `map()`，可以快速将逗号分隔的数字字符串转为数字数组，方便进行数学计算：
```javascript
let numStr = "1,2,3,4,5";
let numArray = numStr.split(",").map(Number);
console.log(numArray); // 输出: [1, 2, 3, 4, 5]
```
