# 秋招学习计划

> 面向 互联网中大厂的 React + TypeScript 前端开发（校招），主栈为 React, TypeScript。

## 本周期目标

只处理以下三个最高优先级主题。完成标准是产出可观察证据，不是新增笔记数量。

### 1. 完成 EXAM-20260730-02 异步一致性考试（优先级 86）

原因：这是已经开始但尚未交付的真实任务，直接覆盖异步竞态、受控状态、接口契约、错误反馈和回归测试；完成它比继续新增笔记更能校准当前画像。

任务：在独立考试工作树完成实现与至少两条回归测试，填写交付说明，然后按既定流程进入独立答辩和现场接管。

验收标准：

- 默认分支、用户显式分支和最终导入 payload 保持一致。
- 关闭或开始新校验后，旧请求结果不能污染界面。
- 通过目标 typecheck、lint、相关测试和 git diff --check。
- 交付说明包含探索链、方案取舍、验证证据和剩余风险。

预计投入：6–10 小时；完成后证据：真实交付、自动化测试、独立答辩和现场接管。

排序输入：目标差距 90 / 招聘相关性 100 / 复习紧迫度 100 / 证据不确定性 30。

### 2. 复测 React Query 缓存与完整交互链（优先级 82）

原因：查询与失效 key 漂移、父行 onClick 遗漏和错误反馈缺失都是会直接造成用户可见故障的重复薄弱点。

任务：在当前考试结卷后，用一个可点击列表项内含 mutation 按钮的真实 Bug 完成 queryKey 工厂、刷新、父子事件隔离和失败反馈，并补交互测试。

验收标准：

- 查询、失效和测试复用同一 queryKey 工厂。
- 普通点击触发父级主行为，内部按钮只执行自身行为。
- mutation 成功产生可观察刷新，失败能被用户感知。
- 相关交互测试覆盖成功、失败和事件隔离。

预计投入：4–6 小时；完成后证据：跨组件真实修复、交互测试和因果说明。

排序输入：目标差距 85 / 招聘相关性 95 / 复习紧迫度 100 / 证据不确定性 30。

### 3. 校准 JavaScript 与 TypeScript 基础（优先级 80）

原因：两类笔记覆盖很广，但目前只有零散实践，尚不足以支撑中大厂校招所需的稳定基础判断。

任务：计时完成 Promise 并发控制代码题，再用 TypeScript 为异步结果、错误和接口 payload 建模；完成后独立解释事件循环、泛型约束和断言风险。

验收标准：

- 并发上限、顺序、失败和空输入都有自动化测试。
- 不使用 any 或无理由双重断言。
- 能解释每个状态变化和 Promise 调度顺序。
- 记录完成时间、卡点、测试结果和独立/辅助边界。

预计投入：4–5 小时；完成后证据：计时代码题、测试结果和独立口述记录。

排序输入：目标差距 75 / 招聘相关性 95 / 复习紧迫度 65 / 证据不确定性 90。

## 时间分配

- 60%：高频薄弱项和重复错误。
- 25%：真实任务、代码题或测试验证。
- 15%：项目表达、面经复盘和简历证据。

## 更新画像的完成条件

- 把实现、运行结果、测试或答辩记录写入对应来源笔记。
- 明确区分独立完成、Agent 辅助和参考答案。
- 重新运行能力画像 Skill；只有通过校验后才更新扫描状态。
