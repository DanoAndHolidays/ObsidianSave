# 响应式布局&移动端优先
实现“移动端优先（Mobile-First）”和“响应式布局”是现代前端开发的核心能力。简单来说，移动端优先是一种设计策略，即先设计和开发最小屏幕（手机）的样式，再逐步扩展到平板和桌面端；而响应式布局则是实现这一策略的技术手段。

以下是实现这一目标的完整核心步骤与最佳实践：

### 设置视口 (Viewport)
https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/meta/name/viewport
在 HTML 的 `<head>` 标签中，必须加入视口元标签。这是移动端适配的第一步，它确保网页的宽度等于设备的屏幕宽度，并禁止用户手动缩放，保证页面按 1:1 的比例渲染：
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

### 移动优先的 CSS 编写
先写移动端的基础样式，再通过媒体查询（Media Queries）为大屏幕添加样式
- **基础样式**：默认就是针对手机端的单列布局、大字号等。
- **渐进增强**：使用 `min-width` 断点，当屏幕宽度大于某个值时，覆盖或增加新的样式。

```css
/* 默认样式：针对移动端（手机） */
.container {
  width: 100%;
  padding: 10px;
}
.card {
  width: 100%; /* 手机上卡片占满整行 */
  margin-bottom: 15px;
}

/* 平板端适配（屏幕宽度 >= 768px） */
@media (min-width: 768px) {
  .container {
    width: 750px;
    margin: 0 auto;
  }
  .card {
    width: 48%; /* 平板上并排显示两个卡片 */
    display: inline-block;
  }
}

/* 桌面端适配（屏幕宽度 >= 1024px） */
@media (min-width: 1024px) {
  .container {
    width: 960px;
  }
  .card {
    width: 31%; /* 桌面端并排显示三个卡片 */
  }
}
```

### 布局&相对单位&弹性媒体
抛弃传统的固定像素（px）布局，全面拥抱现代 CSS 布局方案：
- **弹性布局 (Flexbox)**：非常适合一维布局（如导航栏、卡片列表），可以轻松实现元素的对齐、换行和空间分配。
- **网格布局 (CSS Grid)**：适合复杂的二维页面整体架构，能更直观地划分页面区域。
- **相对单位**：尽量使用 `%`、`rem`、`em`、`vw/vh` 等相对单位来设置宽度、字体大小和间距，代替固定的 `px`。这能让元素随着屏幕大小自动按比例缩放。
- **弹性图片/媒体**：为了防止图片或视频在小屏幕上撑破容器或出现横向滚动条，必须设置以下全局样式：
```css
img, video, iframe {
  max-width: 100%;
  height: auto;
}
```

### 触摸友好与性能优化
移动端主要是手指触摸操作，因此在交互和性能上需要特别注意：
- **触摸目标大小**：按钮、链接等可点击元素的尺寸至少应达到 **44x44px**，且元素之间保留足够的间距，防止误触。
- **简化导航**：在移动端通常使用“汉堡菜单”（折叠导航），而在桌面端再展开为完整的导航栏。
- **性能优化**：移动网络环境复杂，务必对图片进行压缩（或使用 WebP 格式）、采用懒加载（Lazy Load）技术，并压缩合并 CSS/JS 文件，以提升加载速度。

### 真实设备调试
不要只依赖浏览器的开发者工具（F12 的手机模拟模式）。在开发过程中，务必定期在真实的手机、平板设备上进行测试，以确保触摸交互、字体渲染和加载性能符合预期。
