## P0 掌握验收
- 能解释 `const`、`let`、作用域、闭包、`this`、原型链和类型转换的代码行为。
- 能独立实现可靠的异步请求流程，处理并发、错误、取消、超时与加载状态。
- 能在 React 或其他前端框架中保持状态不可变，避免陈旧闭包与副作用泄漏。
- 能使用 ESM 组织模块，识别循环依赖，并说明常见打包与动态加载行为。
- 能安全操作 DOM、表单和浏览器 API，理解 CORS、文件与序列化边界。
