# 07 表单其他属性
> Last Format Time：9/16/2026 19:24:51

---
## readonly vs disabled
核心区别：
```text
readonly = 值存在，只是不允许修改
disabled = 控件当前不可用，不提交数据
```

`disabled` 还可以作用于整个 `fieldset`：
```html
<fieldset disabled>
  <input>
  <button>提交</button>
</fieldset>
```

---
## multiple
表示一个表单控件允许多个值，常见于：
```html
<select multiple>
<input type="file" multiple>
<input type="email" multiple>
```

多个同名值提交时可以出现：
```text
skills=html
skills=js
```

使用 `FormData`：
```js
formData.get("skills");     // 一个值
formData.getAll("skills");  // 所有值
```

## autocomplete
用于告诉浏览器字段代表什么数据，帮助自动填充。

```html
<input autocomplete="name">
<input autocomplete="email">
<input autocomplete="username">
<input autocomplete="current-password">
<input autocomplete="new-password">
```

三个属性职责：
```text
name
→ 提交字段名

type
→ 控件类型、行为、基础验证

autocomplete
→ 字段代表什么数据
```

`autocomplete="off"` 不应当被当作安全措施。

---
## autofocus
```html
<input autofocus>
```

页面显示时自动获得焦点，适合：
```text
搜索框
命令面板
明确需要立即输入的弹窗
```

谨慎使用，因为可能：

- 抢夺用户焦点
- 影响屏幕阅读器体验
- 手机端自动弹出键盘

---
## placeholder
```html
<input placeholder="name@example.com">
```

`placeholder` 是**输入提示 / 示例**，不能替代 `label`，推荐：
```html
<label for="email">邮箱</label>
<input
  id="email"
  name="email"
  type="email"
  placeholder="name@example.com"
>
```

职责：
```text
label
→ 这个字段是什么

placeholder
→ 应该怎么填 / 填写示例
```
