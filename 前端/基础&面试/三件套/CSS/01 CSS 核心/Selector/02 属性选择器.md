## 大小写敏感
例如：
```
<div data-state="OPEN">内容</div>
```

```
[data-state="open"] {}    /* ❌ 不匹配 */

[data-state="open" i] {}  /* ✅ 匹配 */
```

`i` 表示对 ASCII 字符进行不区分大小写的比较

也可以指定 `s`，要求区分大小写：

```
[data-state="open" s] {}
```
