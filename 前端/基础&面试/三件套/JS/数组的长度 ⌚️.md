# 数组的长度 ⌚️
> Last Format Time：9/16/2026 19:24:51

如果你把数组的 `length` 改小，超出新长度的元素会被直接删除

```js
const arr = [1, 2, 3, 4]

arr.length = 2

console.log(arr)     // [1, 2]
console.log(arr[2])  // undefined
console.log(arr[3])  // undefined
```

如果把 length 再变大呢，被删除的数据不会回来：
```js
const arr = [1, 2, 3, 4]

arr.length = 2
arr.length = 4

console.log(arr)
// [1, 2, empty × 2]

console.log(arr[2]) // undefined
```

这里后两个位置是 ==empty slot（空槽）==，不是原来的 `3`、`4`。而且要注意：
```js
const arr = [1, 2]

arr.length = 5

console.log(arr)
// [1, 2, empty × 3]
```

增加 `length` 并不会真的往里面塞：
```js
undefined
```

而只是制造空槽。

比如：
```js
const arr = [1, 2]
arr.length = 3

console.log(2 in arr) // false
console.log(arr[2])   // undefined
```

**数组 `length` 是特殊属性：缩短 `length` 会永久删除尾部元素；增大 `length` 只会产生 empty slots（空槽），不会恢复数据，也不会自动填充 `undefined`。**

这也是为什么有时候会看到这种“清空数组”的写法：
```js
arr.length = 0
```

它会直接把所有数组项删掉。
