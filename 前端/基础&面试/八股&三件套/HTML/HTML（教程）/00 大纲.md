## 必学路线
# 1. HTML 文档骨架
要掌握：
```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>...</title>
</head>
<body>
</body>
</html>
```

重点理解：
- `DOCTYPE`
- `html / head / body`
- `charset`
- `viewport`
- `title`
- `lang`

不是背模板，而是知道每一项解决什么问题。

# 2. HTML 的语义化思想
这是整条 HTML 主线最重要的 mental model：
> HTML 描述的是“这个东西是什么”，而不是“这个东西长什么样”。

重点：
```html
div
span
header
footer
main
nav
section
article
aside
```

真正搞清：

```text
section vs div
article vs section
header 到底是不是只能出现一次
main 为什么特殊
nav 什么时候应该用
aside 表达什么
```


# 3. 标题与文档结构

```html
<h1>
<h2>
<h3>
...
```

重点不是字体大小，而是文档层级。

例如：

```text
h1 页面主题
├─ h2 第一章节
│  ├─ h3 子章节
│  └─ h3 子章节
└─ h2 第二章节
```

还会讲：

- 一个页面到底能不能有多个 `h1`
    
- heading 为什么和 Accessibility / SEO 有关系
    
- 为什么不能因为默认样式不好看就用 `div`
    


# 4. 文本语义

很多标签看起来效果差不多，但语义不同：

```html
<strong>
<b>

<em>
<i>

<mark>
<small>
<del>
<ins>

<code>
<pre>
<blockquote>
<q>
```

例如：

```html
<strong>重要</strong>
```

和：

```html
<b>加粗</b>
```

不是完全一回事。

这一块不用死背全部标签，但要建立：

> **视觉效果 ≠ HTML 语义**


# 5. `<a>` 与导航

这是前端必须非常熟的。

```html
<a href="/users">用户</a>
```

重点：

```html
href
target
rel
download
```

以及：

```text
相对 URL
绝对 URL
锚点
mailto:
tel:
```

最重要的问题：

> `<a>` 和 `<button>` 到底什么时候用？

基本判断：

```text
发生导航
→ a

执行操作
→ button
```

这个在 React 项目里非常重要。


# 6. `<button>` 与原生交互元素

理解：

```html
<button type="button">
<button type="submit">
<button type="reset">
```

以及为什么：

```html
<div onclick="...">
```

通常不应该模拟 Button。

还会涉及：

```html
<details>
<summary>

<dialog>
```

这些现代 HTML 原生交互能力。

核心思想：

> **能使用 Native HTML，就不要先用 div + JS 重新造。**


# 7. Form：表单基础

这是 HTML 最值得重点补的一部分。

```html
<form>
  <label for="email">邮箱</label>
  <input id="email" name="email" />
  <button type="submit">提交</button>
</form>
```

真正理解：

```text
form
input
textarea
select
option
button
label
```

以及：

```html
action
method
name
value
```


# 8. Input 类型

必须熟悉常见：

```html
<input type="text">
<input type="password">
<input type="email">
<input type="number">
<input type="checkbox">
<input type="radio">
<input type="file">
<input type="date">
```

然后理解：

> 不同 `type` 不只是长得不一样，浏览器行为也不同。

例如：

```html
type="email"
```

可以参与浏览器原生 validation（校验）。

尤其必须搞明白：


这种问题。


# 10. Form 提交模型

这一块非常值得深入。

理解：

```text
点击 submit
    ↓
浏览器找到所属 form
    ↓
constraint validation
    ↓
submit
    ↓
根据 name/value 构造 form data
```

然后理解：

```html
<form method="get">
<form method="post">
```

以及：

```text
name 为什么非常重要？

checkbox 没选中会提交吗？

button 为什么可能提交表单？

Enter 为什么可能触发表单提交？
```

这类浏览器原生行为。


# 11. Label 与表单可访问性

例如：

以及：



# 12. HTML Accessibility 基础

不深入 CSS，只从 HTML 本身看。

重点：

```text
Native Semantics
Keyboard
Focus
Screen Reader
Accessible Name
```

涉及：

```html
alt
label
title
tabindex
hidden
aria-*
role
```

但重点原则是：

```text
Native HTML
    ↓
不够表达时再使用 ARIA
```

而不是：

```html
<div role="button">
```

到处模拟原生 HTML。

# 15. Table

不要使用 Table 做页面布局，但真正的二维表格数据应该使用：

```html
<table>
  <caption>销售数据</caption>

  <thead>
    ...
  </thead>

  <tbody>
    <tr>
      <th>商品</th>
      <td>100</td>
    </tr>
  </tbody>
</table>
```

需要理解：

```text
table
caption
thead
tbody
tfoot
tr
th
td
```

尤其：

```html
scope="col"
scope="row"
```

与表格 Accessibility。


# 16. HTML 资源加载

最后这一块和真正的前端工程关系很大。

### CSS
```html
<link rel="stylesheet" href="app.css">
```

### JavaScript
```html
<script src="app.js"></script>
```

重点深入：

```html
<script defer>
<script async>
<script type="module">
```

真正搞清楚：

```text
HTML Parsing
    ↓
遇到 script
    ↓
下载 / 执行
    ↓
是否阻塞 Parser
```

然后了解：

```html
<link rel="preload">
<link rel="preconnect">
<link rel="icon">
```

这时候 HTML 就开始和浏览器加载机制连接起来了。


# 最终路线

我建议实际按照这个顺序学：

```text
HTML Mental Model
        ↓
1. 文档结构
2. Semantic HTML
3. Heading / Text Semantics
        ↓
4. a
5. button
6. Native Interactive Elements
        ↓
7. Form
8. Input
9. Form Attributes
10. Form Submission
11. Label / fieldset
        ↓
12. Accessibility
        ↓
13. Image
14. Media / iframe
15. Table
        ↓
16. Script / Resource Loading
```

其中对一个前端开发来说，我认为优先级最高的是：

```text
Semantic HTML
      +
a / button
      +
Form 原生行为
      +
Accessibility
      +
script 加载行为
```

这五块掌握之后，你的 HTML 就不再只是“我会写 `<div>`”，而是真的知道**浏览器原生给了你什么能力**。

接下来我们就严格沿这条路线走，**不夹 CSS**。第一部分可以直接从 **「HTML 到底什么叫语义，以及 section / article / div / main 怎么选」** 开始。
