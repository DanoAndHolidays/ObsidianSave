# 固定长宽比
过去的解决方案是使用 `padding`

一个元素的 `padding` 如若设置为百分比，则代表的是以包含块宽度为基准，根据这个原理，可设置长宽比

但实际上意义有限，毕竟你把 padding 给占了，content 无任何区域

现代化的解决方案是使用长宽比的 CSS 属性: `aspect-ratio`

举一个最常见的场景：视频封面需要始终保持 16:9 的宽高比，不管容器宽度如何变化，高度都能自动调整。

---
## 现代方案
16:9 视频容器

宽度随父容器变化，高度自动保持 16:9
```HTML
<div class="video">
  <span>视频内容</span>
</div>
```

```css
.video {
  width: 100%;
  max-width: 400px;
  aspect-ratio: 16 / 9;

  background: #193b66;
  color: white;
}
```

核心就是：
```css
aspect-ratio: 16 / 9;
```

当宽度确定、高度为 `auto` 时，浏览器会按照比例计算高度

|宽度|高度（自动计算）|
|---|---|
|400px|225px|
|320px|180px|
|160px|90px|

而且，容器内部仍然可以正常放置内容，不需要额外处理定位

---
## 旧方案`
在没有 `aspect-ratio` 的年代，可以这么写：
```css
.video {
  width: 100%;
  height: 0;
  padding-top: 56.25%; /* 9 / 16 */
  position: relative;
}

.video-content {
  position: absolute;
  inset: 0;
}
```

```css
<div class="video">
  <div class="video-content">
    视频内容
  </div>
</div>
```

为什么 `padding-top: 56.25%`？因为百分比 `padding-top` 是根据包含块的宽度计算的。

假设包含块宽度为 400px：400 * 56.25 = 225px 

由于 `height: 0`，容器高度主要由上内边距撑开，形成 400 × 225 的区域。

但是旧方案有个问题：这个高度来自 `padding`，而不是正常的内容区域。所以我们通常需要通过 `position: absolute` 将子元素放进这个区域。

---
## 常见应用
```css
.card-image {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}
```

注意： `aspect-ratio` 设置的是首选宽高比。如果同时显式指定 `width` 和 `height`（都不是 `auto`），通常就不会通过比例自动计算尺寸了。另外，内容也可能影响自动尺寸。
