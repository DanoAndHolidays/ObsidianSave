# Variables 变量
**CSS 变量（自定义属性）**：`--color: red;`，使用 `var(--color)`

**解决的问题**：

- **统一主题切换**：修改根变量一键换肤，比如[[深色模式]]

- **减少重复**：颜色/间距等全局值定义一次，处处引用

- **动态修改**：JS 通过 `el.style.setProperty('--color', 'blue')` 更新变量

- **继承和作用域**：在任意选择器中定义，子元素继承

- **与预处理器的区别**：CSS 变量是运行时（非编译时），可以动态计算

- **组合使用**：`var(--n, 10px)` 默认值、`calc(var(--n) * 2)` 计算
