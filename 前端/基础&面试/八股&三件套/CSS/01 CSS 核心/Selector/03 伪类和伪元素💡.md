## 伪类
[伪类参考](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Selectors/Pseudo-classes)
伪类是基础选择器的一种，它用于选择处于特定状态的元素，比如当它们是这一类型的第一个元素时，或者是当鼠标指针悬浮在元素上面的时候

伪类就是开头为冒号的关键字。例如，`:hover` 就是一个伪类

一个 `a` 标签中推荐的伪类顺序：
![[Pasted image 20260916233842.png]]

伪类可以先分成以下几个常用类别：

| 分类    | 常见伪类                                      | 匹配依据       |
| ----- | ----------------------------------------- | ---------- |
| 用户交互  | `:hover`、`:active`                        | 用户操作状态     |
| 焦点    | `:focus`、`:focus-visible`、`:focus-within` | 焦点状态       |
| 表单状态  | `:checked`、`:disabled`、`:invalid`         | 控件状态       |
| 结构位置  | `:first-child`、`:nth-child()`             | DOM 兄弟元素位置 |
| 类型位置  | `:first-of-type`、`:nth-of-type()`         | 同类型兄弟元素位置  |
| 逻辑与关系 | `:not()`、`:is()`、`:where()`、`:has()`      | 选择器条件与元素关系 |

你之前学习过 HTML Form，因此这里直接从原生状态的角度理解

```
<input type="checkbox" checked>
<input type="text" disabled>
<input type="email" required>
```

| 伪类                   | 含义                     |
| -------------------- | ---------------------- |
| `:enabled`           | 支持禁用状态且当前可用            |
| `:disabled`          | 当前处于禁用状态               |
| `:checked`           | checkbox、radio 等处于选中状态 |
| `:required`          | 表单控件要求填写               |
| `:optional`          | 表单控件不要求填写              |
| `:valid`             | 满足原生约束校验               |
| `:invalid`           | 不满足原生约束校验              |
| `:placeholder-shown` | 当前正在显示 placeholder     |

## 伪元素
[伪元素参考](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Selectors/Pseudo-elements)
表现得是像你往标记文本中加入全新的 HTML 元素一样，而不是向现有的元素上应用类

伪元素开头为双冒号 `::`

### `::before` 和 `::after`
```
<div class="card">Hello</div>
```

```
.card::before {
  content: "★ ";
  color: orange;
}

.card::after {
  content: " ✓";
  color: green;
}
```

最终视觉效果：
![[Pasted image 20261017220811.png]]

它们代表的不是两个真实的 HTML 元素

可以把它们的布局关系近似理解成：
```
div.card
├── ::before   （生成内容）
├── "Hello"    （原始文本）
└── ::after    （生成内容）
```

但是注意：这个结构只是帮助理解渲染行为，不是真实 DOM 树。

因此：
```
document.querySelector(".card::before");
```

不会得到一个伪元素节点。`querySelector()` 不会返回伪元素

如果需要读取伪元素的计算样式，可以使用：
```
const el = document.querySelector(".card");

const style = getComputedStyle(el, "::before");

console.log(style.content);
```

对于普通的 `::before` 和 `::after`，通常需要设置 `content`，否则不会生成对应的盒子

例如：
```
.card::before {
  content: "";
  display: block;
  width: 10px;
  height: 10px;
  background: red;
}
```

即使没有任何文字，只要提供 `content: ""`，也可以生成一个用于装饰的盒子

这在项目中非常常见，例如状态圆点、下划线、装饰边框等

除了 `::before`、`::after`，还有一类伪元素可以匹配已有内容的特定部分。

### `::first-letter`
首字母
```
p::first-letter {
  font-size: 32px;
  color: red;
}
```

用于设置符合条件的元素的首字符样式，常用于文章首字下沉。

### `::first-line`
第一行
```
p::first-line {
  font-weight: bold;
}
```

这里的“第一行”不是 HTML 中第一行源代码，而是浏览器布局后实际形成的第一行文本。

如果容器宽度变化、文字重新换行，`::first-line` 对应的内容也会变化。

这能和你之前学过的 Layout（布局）模型联系起来。

### `::selection`
用户选中的文字
```
::selection {
  background: yellow;
  color: black;
}
```

选中网页文字时，会使用指定的高亮样式。它只支持部分 CSS 属性，并非所有属性都可以设置。

### `::placeholder`
输入框占位文本
```
<input placeholder="请输入用户名">
```

```
input::placeholder {
  color: gray;
  opacity: 0.7;
}
```

注意下面两个东西不同：
```
input:placeholder-shown {} /* 伪类 */
input::placeholder {}      /* 伪元素 */
```

前者匹配当前正在显示占位文本的 `input` 元素本身，后者用于设置占位文本的样式。

### `::marker`
列表标记
```
li::marker {
  color: red;
  font-size: 20px;
}
```

用于设置列表前面的圆点或数字等标记样式

`::before` 和 `::after` 伪元素与 `content` 属性的共同使用，在 CSS 中被叫做“生成内容”，而且你会见到这种技术被用于完成各种任务。[CSS Arrow Please](https://cssarrowplease.com/) 网站就是一个著名的示例，它帮你用 CSS 生成一个箭头。在你创建你的箭头的时候看下 CSS，你将会看到实际使用的 [`::before`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Selectors/::before) 和 [`::after`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Selectors/::after) 伪元素。无论什么时候你看到了这些选择器，都要看下 [`content`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/content) 属性，以了解 HTML 元素中添加了什么。
