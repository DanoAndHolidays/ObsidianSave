# 行内元素对齐
`vertical-align` 用于控制行内级盒子在行内格式化上下文（IFC）中的垂直对齐方式，也可用于表格单元格

它不是通用的垂直居中属性，不能直接用来让普通块级元素在父容器中垂直居中

![[Pasted image 20261014193741.png]]
基线最初是字体排版中的概念，大部分西文字母沿着基线排列，`g`、`p`、`y` 等字母的下伸部分会延伸到基线下方[[02 Line Height & Line Box]]

在 IFC 中，不仅文字有基线，行内级盒子也可以根据各自的规则确定基线

---
## 父元素基线
CSS 使用 Strut（虚拟支撑盒） 模型解释块容器中的行内布局

可以想象浏览器在块容器的每个行盒中放置了一个宽度为 0 的虚拟行内盒子：

- 继承块容器的字体属性

- 使用块容器的 `line-height`

- 根据字体度量建立基线参考

- 不占据水平空间，但会参与行盒高度计算

```
<p class="container">
  Hello
  <img src="icon.svg" />
</p>
```

```
.container {
  font-size: 20px;
  line-height: 30px;
}
```

即使删除 `Hello`，只剩下图片，块容器仍能通过 Strut 提供基线参考

因此，`vertical-align: baseline` 所说的与父元素基线对齐，不是指父元素的盒模型边缘，而是父级行内排版所提供的基线参考

如果父元素本身是行内元素，则使用该父级行内盒相应的基线作为参考

---
## vertical-align

|属性值|作用|
|---|---|
|`baseline`|与父级基线对齐，默认值|
|`middle`|元素中点与父级基线向上半个 x-height 的位置对齐|
|`top`|与整个行盒顶部对齐|
|`bottom`|与整个行盒底部对齐|
|`text-top`|与父元素字体顶部对齐|
|`text-bottom`|与父元素字体底部对齐|
|`sub` / `super`|下标 / 上标对齐|
|`5px` / `-5px`|相对于基线向上 / 向下偏移|
|`20%`|按自身 `line-height` 的百分比计算偏移|

注意，`vertical-align: middle` 不是真正的几何居中，因为它依赖字体的 x-height（小写字母 x 的高度度量）

### 图片底部空隙
![[Pasted image 20261014193810.png]]

```html
<div class="container">
  Hello
  <img src="photo.png" />
  World
</div>
```

`img` 默认作为行内替换元素参与 IFC，其==基线==通常位于==底部外边距边缘==，

默认采用 `vertical-align: baseline`，所以图片底部与父级基线对齐，而行盒还需要保留基线下方的字体排版空间。

因此，图片下面可能存在空隙，这通常不是 `margin` 或 `padding` 导致的

解决方式：
```
/* 独立展示图片，推荐 */
img {
  display: block;
}

/* 需要保留行内布局 */
img {
  vertical-align: bottom;
}
```

对于只有图片的简单容器，`line-height: 0` 也可能消除空隙，但会影响文本排版，不推荐作为通用方案。

### 图标与文字对齐
![[Pasted image 20261014194337.png]]
```
<span>
  <img src="icon.svg" class="icon" />
  设置
</span>
```

方案一：`vertical-align: middle`
```
.icon {
  width: 20px;
  height: 20px;
  vertical-align: middle;
}
```

适用于文字中插入小图标，但不保证视觉上的绝对居中。

方案二：Flex（组件开发更推荐）
```
.label {
  display: inline-flex;
  align-items: center;
  gap: 6px;
}
```

也可以微调像素值

Flex 将内部项目的盒子沿交叉轴居中，更适合按钮、菜单、导航等组件

注意：`vertical-align` 不负责 Flex Item 之间的对齐，但可以影响整个 `inline-flex` 容器在外部文本行中的对齐

## `inline-block` 的基线
`inline-block` 的基线不一定是盒子底部

一般情况下：

- 内部存在普通流行盒，且 `overflow: visible`：使用内部最后一个行盒的基线。
- 没有普通流行盒，或者 `overflow` 的计算值不是 `visible`：使用底部外边距边缘作为基线。

因此，修改 `inline-block` 内部内容或者 `overflow`，可能改变它与外部文字的对齐位置

---
## 对行盒高度的影响
`vertical-align` 可能影响 Line Box 的最终高度
```
p {
  line-height: 24px;
}

span {
  vertical-align: 20px;
}
```

`span` 向上偏移后，可能使整个行盒变高。

行盒高度并不简单等于 `line-height`，也不是所有子元素 `height` 的最大值，而是需要容纳参与行内布局的盒子在垂直对齐之后所占据的范围。
