# 01 字体基础
Typography（排版）不仅涉及字体大小、颜色、粗细，还包括字体选择、字形度量、行高、基线、换行和文本布局

几个重要概念：

- Font（字体）：包含字形和字体度量信息
- Font Family（字体族）：具有共同设计风格的一组字体
- Glyph（字形）：字符最终呈现的图形
- Font Metrics（字体度量）：描述字体尺寸、基线等排版信息

核心：`font-size` 决定字体使用的 em 方框尺度，不等于实际可见字形的高度

因此即使两个字体的 `font-size` 都为 `16px`，实际视觉大小也可能不同

## 字体选择与回退
```
body {
  font-family:
    system-ui,
    "PingFang SC",
    "Microsoft YaHei",
    sans-serif;
}
```

浏览器按字体列表顺序查找可用字体：

- `system-ui`：系统界面字体
- `sans-serif`：无衬线通用字体族
- `serif`：衬线通用字体族
- `monospace`：等宽通用字体族

### Font Fallback 字体回退
字体回退可以发生在字符级别

例如：
```
<p>Hello 你好 👋</p>
```

英文、中文、Emoji 可能分别由不同字体渲染

影响： 不同字体的度量和字符宽度不同，字体回退或 Web Font 加载可能导致换行变化，甚至发生布局偏移（Layout Shift）

## font-size
字号

|单位|计算基准|
|---|---|
|`px`|CSS 像素，不等于固定数量的物理屏幕像素|
|`em`|用于 `font-size` 时，相对于父元素的计算字号|
|`rem`|相对于根元素的计算字号|

```
html {
  font-size: 16px;
}

.card {
  font-size: 1.25em; /* 20px */
}

.card p {
  font-size: 0.8em; /* 16px */
}

.card h2 {
  font-size: 1.5rem; /* 24px */
}
```

注意：

- `em` 用于 `font-size` 时，可能因嵌套而逐层放大或缩小
- `em` 用于 `padding`、`margin` 等属性时，通常相对于当前元素自身的计算字号
- 工程中常使用 `rem` 定义全局字号尺度，使用 `em` 实现局部随字号缩放

## font-weight
常见字重：

|数值|名称|
|---|---|
|400|Regular|
|500|Medium|
|600|Semibold|
|700|Bold|

```
.title {
  font-weight: 600;
}
```

需要注意：

1. 设置 `600` 不代表字体一定存在对应字重文件
2. 浏览器可能选择其他可用字重，或合成粗体
3. 可变字体（Variable Font）可以支持连续的字重范围

可以禁止浏览器合成字体样式：
```
.text {
  font-synthesis: none;
}
```

## font-style
字体样式
```
.a {
  font-style: normal;
}

.b {
  font-style: italic;
}

.c {
  font-style: oblique;
}
```

- `normal`：正常字体
- `italic`：请求专门设计的斜体字形
- `oblique`：请求倾斜样式，可能使用真实字形或由浏览器合成
