# 文字排版

---
## 优化文本换行
`text-wrap` 用于控制文本的换行策略。相比 `word-break`、`overflow-wrap` 主要决定在哪里允许断行，`text-wrap` 还可以控制浏览器如何优化断行结果

|属性值|作用|场景|
|---|---|---|
|`wrap`|正常自动换行|普通文本|
|`balance`|尽量平衡各行文本长度|标题、短文案|
|`pretty`|优化换行质量，减少过短的末行|正文、说明文字|
|`nowrap`|不自动换行|单行文本|

```
h1, h2 {
  text-wrap: balance;
}

.article p {
  text-wrap: pretty;
}
```

注意：

- `balance` 并不保证每行字符数量相等，通常更适合短文本。

- `pretty` 并不保证消除所有孤立单词，且可能增加排版计算开销。

- `text-wrap` 不会替代 `overflow-wrap`、`word-break` 的断行规则。

## Fluid Typography 流体字体
流体字体是指字体大小随着视口或容器尺寸连续变化，而不是只通过媒体查询进行阶梯式调整。

常用 `clamp()` 实现：
```
.title {
  font-size: clamp(
    1.5rem,
    calc(1rem + 2vw),
    3rem
  );
}
```

计算模型：
```
实际字号 = clamp(最小值, 首选值, 最大值)
```

- `rem`：结合根元素字号，提供相对尺寸。

- `vw`：根据视口宽度变化。

- `clamp()`：限制字号的上下界。


注意不要仅使用 `vw` 控制字体大小，避免小屏幕字号过小以及文本缩放问题。即使混合 `rem` 与 `vw`，也需要检查用户放大文本时是否能够正常适配。

流体字体通常适合 Hero 标题、Banner、展示型页面，表格和表单等区域更适合相对稳定的字号。

## Web Fonts网络字体
Web Font 允许网页加载自定义字体文件，不必完全依赖操作系统字体

通过 `@font-face` 声明：
```
@font-face {
  font-family: "MyFont";
  src: url("/fonts/my-font.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: "MyFont", Arial, sans-serif;
}
```

`@font-face` 用于注册字体资源，并不代表字体文件会立即下载。通常在页面实际需要该字体时才会触发加载。

### 字体加载问题

- FOIT（Flash of Invisible Text）：字体加载期间，文字暂时不可见。
- FOUT（Flash of Unstyled Text）：先显示回退字体，之后切换成自定义字体。

### `font-display`
控制自定义字体加载期间的显示策略

|属性值|行为|
|---|---|
|`auto`|由浏览器决定|
|`block`|短暂隐藏文字，等待字体|
|`swap`|立即显示回退字体，字体加载完成后替换|
|`fallback`|短暂等待，随后显示回退字体，限制替换时间|
|`optional`|优先显示文字，本次可能不再替换字体|

通常可根据项目要求选择 `swap` 或 `optional`，不存在统一的最佳值

### 字体切换与 CLS
不同字体的 Font Metrics（字体度量）不同，包括字符宽度、上升部、下降部等

切换字体可能改变文字换行和布局尺寸，进而产生 CLS（累积布局偏移）

可以通过 `@font-face` 的字体度量描述符进行优化：
```
@font-face {
  font-family: "AdjustedFallback";
  src: local("Arial");

  size-adjust: 98%;
  ascent-override: 90%;
  descent-override: 22%;
  line-gap-override: 0%;
}
```

其中：

- `size-adjust`：调整字形及相关度量的整体比例。

- `ascent-override`：覆盖上升部度量。

- `descent-override`：覆盖下降部度量。

- `line-gap-override`：覆盖行间距度量。


具体数值应根据字体实际度量计算，不能直接照搬

### 字体资源优化

- 优先使用 `woff2`。

- 对首屏关键字体可以使用 `preload` 提前加载。

- 不要预加载所有字体，以免与其他关键资源竞争带宽。

- 中文字体文件较大，可以进行字体子集化（Font Subsetting），并结合 `unicode-range` 按字符范围加载。

## 中文排版实践
中文具有自己的断行规则，大多数情况下不需要额外使用 `word-break: break-all`。
```
.article {
  word-break: normal;
  overflow-wrap: normal;
}
```

如果需要处理超长 URL、连续英文等内容，可以按需使用：
```
.article {
  overflow-wrap: anywhere;
}
```

其他注意事项：

- 使用 `<html lang="zh-CN">` 声明页面语言。

- 使用合理的中英文字体回退链。

- 合理设置 `line-height` 和文本容器宽度。

- `ch` 单位基于字符 `0` 的字形前进宽度，不等于汉字数量。
