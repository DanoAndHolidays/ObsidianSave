# 04 文本布局
浏览器在 IFC（行内格式化上下文）中，根据容器可用宽度和文本断行规则，将文字分配到一个或多个 **Line Box（行盒）** 中

整体过程可以理解为：

**空白处理 → 确定断行机会 → 根据宽度排版 → 生成行盒 → 处理溢出**

涉及的核心属性：

- `white-space`：控制空白字符与换行行为

- `word-break`：控制允许在哪里断行

- `overflow-wrap`：提供额外的断行机会，防止长内容溢出

- `overflow`：控制溢出内容如何处理

- `text-overflow`：控制行内方向上被裁剪文本的省略标记

- `line-clamp`：限制文本显示行数

---
## 空白与换行
HTML 中的连续普通空格、源码换行默认会进行空白折叠（Whitespace Collapsing），不会全部保留，`white-space`：

|属性值|连续空格|源码换行|自动换行|
|---|---|---|---|
|`normal`|合并|不保留为强制换行|允许|
|`nowrap`|合并|不保留为强制换行|禁止|
|`pre`|保留|保留|禁止|
|`pre-wrap`|保留|保留|允许|
|`pre-line`|合并|保留|允许|

例如，展示用户输入的多行文本：
```
.description {
  white-space: pre-wrap;
}
```

这样可以保留用户输入的普通空格和换行，同时允许长文本自动换行。

现代 CSS 中，`white-space` 还可以拆分理解为：

- `white-space-collapse`：空白如何处理
- `text-wrap-mode`：是否允许自动换行

---
## word-break
控制断行规则，不同语言默认的断行机会不同：

- 中文：通常允许在汉字之间断行，但需要遵循标点等排版规则
- 英文：通常优先在单词之间断行
- 超长英文单词：没有合法断行机会时，可能溢出容器

常见属性：

|属性值|作用|
|---|---|
|`normal`|遵循正常的语言断行规则|
|`break-all`|对非 CJK 文本允许在单词内部断行|
|`keep-all`|限制 CJK 字符之间的自动断行|

```
.text {
  word-break: break-all;
}
```

`break-all` 比较激进，可能把原本可以完整移动到下一行的英文单词直接拆开，因此不推荐无差别地用于普通正文。

---
## overflow-wrap
长文本溢出时的断行

`overflow-wrap` 主要用于处理长单词、URL、用户 ID 等无法正常断开的内容
```
.content {
  overflow-wrap: anywhere;
}
```

浏览器优先使用正常断行机会，必要时允许在连续字符串内部额外断行

常用值：

|属性值|作用|
|---|---|
|`normal`|只使用正常断行机会|
|`anywhere`|必要时允许额外断行，并影响 `min-content` 计算|
|`break-word`|断行效果类似 `anywhere`，但新增断行机会不参与 `min-content` 计算|

`word-break` **与** `overflow-wrap` **的区别：

- `word-break`：主要改变文本的断行规则
- `overflow-wrap`：主要在正常断行机会不足时提供额外断行机会


实际项目中，对于不确定长度的用户生成内容，通常优先：
```
.user-content {
  overflow-wrap: anywhere;
}
```

而不是一律使用 `word-break: break-all`

## 单行文本省略号
常见实现：
```
.title {
  width: 200px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

三个属性分别负责：

1. `white-space: nowrap`：禁止自动换行

2. `overflow: hidden`：裁剪溢出内容

3. `text-overflow: ellipsis`：在行内方向的截断位置显示省略号


注意：

- `text-overflow` 本身不负责裁剪内容
- 必须存在实际的宽度约束和文本溢出
- 它不是多行省略号的解决方案

### Flex 中省略号不生效
```
.card {
  display: flex;
  width: 300px;
}

.content {
  flex: 1;
  min-width: 0;
}

.title {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

**原因：** Flex Item 默认的 `min-width: auto` 可能受到内容内在尺寸约束，导致元素无法正常收缩。

给对应的 Flex Item 设置 `min-width: 0`，允许其缩小，内部文本才有机会溢出并显示省略号。

这与之前学习的 Intrinsic Sizing、`min-content` 和 Flex 自动最小尺寸直接相关。

## 多行文本省略号
例如，文本最多显示三行：
```
.description {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}
```

CSS 也定义了标准属性：
```
.description {
  line-clamp: 3;
}
```

但标准写法的浏览器支持仍需注意，实际项目中可以优先考虑兼容性更成熟的 `-webkit-line-clamp` 方案
