# 深色模式
> Last Format Time：8/13/2026 15:18:22

CSS 主题切换（Theme Switching）的核心原理是：根据当前主题状态，为元素应用不同的 CSS 样式

---
## 传统方案
class + JavaScript，通过 JavaScript 修改根元素的类名，触发 CSS 选择器匹配不同样式：
```
/* 浅色模式 */
body {
  background: white;
  color: black;
}

/* 深色模式 */
body.dark {
  background: #111827;
  color: white;
}
```

```
document.body.classList.toggle("dark");
```

缺点：组件多时，需要维护大量 `.dark .xxx` 样式，维护成本较高

---
## 主流方案
CSS Variables + data-theme，使用 CSS 自定义属性（Custom Properties）管理主题颜色，组件只消费变量，不关心具体主题：
```
/* 浅色主题 */
:root {
  --bg: #ffffff;
  --text: #111827;
  --primary: #2563eb;
}

/* 深色主题 */
:root[data-theme="dark"] {
  --bg: #111827;
  --text: #f9fafb;
  --primary: #60a5fa;
}

/* 组件消费变量 */
.card {
  background: var(--bg);
  color: var(--text);
}
```

通过 JavaScript 切换，这里的 `documentElement` 是 `<html>`：
```
document.documentElement.dataset.theme = "dark";
```

核心模型：

JS 修改 `data-theme` → CSS 重新匹配主题变量声明 → `var()` 引用得到新值 → 浏览器更新样式。

优点：主题逻辑集中管理，组件与具体颜色解耦，适合大型项目。

### Custom Data Attributes
`data-theme` 就是 HTML5 中 `data-*` 自定义数据属性（Custom Data Attributes）的一种。

它并不是 CSS 专门为主题切换设计的属性，而是开发者自己定义的。浏览器并不知道 `data-theme="dark"` 代表深色模式

HTML 允许开发者通过 `data-*` 为元素添加自定义数据

例如：
```
<div
  data-id="1001"
  data-user-name="Dano"
  data-status="active"
  data-theme="dark"
>
  Hello
</div>
```

这些属性都是开发者自定义的，浏览器不会因为它们的名字而自动执行对应的业务逻辑。

JavaScript 可以通过 `dataset` 读取它们：
```
const el = document.querySelector("div");

console.log(el.dataset.id);       // "1001"
console.log(el.dataset.userName); // "Dano"
console.log(el.dataset.status);   // "active"
console.log(el.dataset.theme);    // "dark"
```

这里有几个规则：

- HTML 属性以 `data-` 开头。
- JavaScript 使用 `element.dataset` 访问。
- `data-user-name` 对应 `dataset.userName`，采用驼峰命名。
- `dataset` 中的属性值是字符串。


当然，也可以修改：
```
el.dataset.status = "disabled";
```

DOM 会变成：
```
<div data-status="disabled">Hello</div>
```

### CSS 属性选择器（Attribute Selector）
```
/* 选择具有 data-theme 属性的元素 */
[data-theme] {
  /* ... */
}

/* 选择 data-theme 值为 dark 的元素 */
[data-theme="dark"] {
  /* ... */
}
```

例如：
```
<div data-status="active">运行中</div>
<div data-status="disabled">已禁用</div>
```

```
[data-status="active"] {
  color: green;
}

[data-status="disabled"] {
  color: gray;
}
```

浏览器会根据元素的属性值匹配不同 CSS 规则

### 完整例子
##### HTML
```
<html data-theme="light">
  <body>
    <h1>我的网站</h1>
    <button id="toggle">切换主题</button>
  </body>
</html>
```

初始时，根元素 `html` 有一个自定义属性：
```
data-theme="light"
```

##### CSS
```
/* 默认浅色 */
:root {
  --bg: white;
  --text: black;
}

/* 深色模式 */
:root[data-theme="dark"] {
  --bg: #111827;
  --text: white;
}

body {
  background: var(--bg);
  color: var(--text);
}
```

注意这个选择器：
```
:root[data-theme="dark"]
```

它表示：同时满足 `:root` 和 `[data-theme="dark"]` 的元素,在普通 HTML 文档中，`:root` 匹配 `<html>` 元素

##### JavaScript
```
const root = document.documentElement;

document.querySelector("#toggle")
  .addEventListener("click", () => {
    root.dataset.theme =
      root.dataset.theme === "light"
        ? "dark"
        : "light";
  });
```

每次点击按钮，就会修改 `<html>` 的 `data-theme` 属性。`data-theme="light" → "dark"`

实际就是切换了一套新的 CSS 变量的值，颜色就换了

## 自动跟随系统
`prefers-color-scheme` 是 CSS 媒体特性，用来检测用户的系统浅色 / 深色偏好。
```
:root {
  --bg: white;
  --text: black;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #111827;
    --text: white;
  }
}
```

不需要 JavaScript，即可自动跟随系统偏好

---
## 同时支持手动切换与系统主题
一般设计三种主题状态：

- `light`：强制浅色
- `dark`：强制深色
- `system`：跟随系统

```
:root {
  --bg: white;
  --text: black;
}

/* 没有手动主题时跟随系统 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme]) {
    --bg: #111827;
    --text: white;
  }
}

:root[data-theme="dark"] {
  --bg: #111827;
  --text: white;
}
```

```
function setTheme(theme) {
  const root = document.documentElement;

  if (theme === "system") {
    root.removeAttribute("data-theme");
  } else {
    root.dataset.theme = theme;
  }

  localStorage.setItem("theme", theme);
}
```

页面初始化时应尽早恢复保存的主题，避免主题闪烁（FOUC）。

## 现代方案
color-scheme + light-dark()
`color-scheme` 声明元素支持的配色方案，`light-dark()` 根据当前使用的配色方案选择颜色。
```
:root {
  color-scheme: light dark;

  --bg: light-dark(#ffffff, #111827);
  --text: light-dark(#111827, #f9fafb);
}

body {
  background: var(--bg);
  color: var(--text);
}
```

手动切换可通过覆盖 `color-scheme` 实现：
```
:root[data-theme="light"] {
  color-scheme: light;
}

:root[data-theme="dark"] {
  color-scheme: dark;
}
```

注意：

- `color-scheme` 还会影响浏览器原生表单控件、滚动条等外观。

- `light-dark()` 负责选择颜色，不负责存储用户主题偏好。

- `color-scheme: dark` 不会自动把所有写死的浅色 CSS 颜色转换成深色。
