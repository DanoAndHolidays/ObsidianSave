# 撤销重做数据管理器
你正在开发一个在线文档编辑器，用户执行以下操作：

1. 输入 `A`
2. 输入 `B`
3. 输入 `C`
4. 点击撤销
5. 再点击撤销
6. 点击重做

---
## 核心数据结构
两个栈 + 当前状态
```ts
class HistoryManager<T> {
  private past: T[] = [];     // 历史状态
  private present: T;         // 当前状态
  private future: T[] = [];   // 撤销后可重做的状态
}
```

这里使用的是栈（Stack），它具有后进先出（LIFO）的特性：

- `past`：记录当前状态之前的历史，用来撤销
- `present`：保存当前实际使用的数据
- `future`：记录被撤销的状态，用来重做

撤销操作：
```ts
future.push(present)
present = past.pop()
```

重做操作：
```
past.push(present)
present = future.pop()
```

还有一个非常容易在面试中遗漏的规则：撤销后如果执行了新的修改，必须清空 future

例如：
```
A → AB → ABC
      ↑
    撤销到 AB

在 AB 基础上输入 D

A → AB → ABD
```

此时 `ABC` 已经不属于当前编辑分支，不能再通过重做恢复。=

### 完整 TypeScript 实现
这里写一个泛型管理器，它可以管理字符串、对象、数组等可克隆的数据
```ts
class HistoryManager<T> {
  private past: T[] = [];
  private future: T[] = [];
  private present: T;

  constructor(
    initialState: T,
    private readonly maxHistory = 100
  ) {
    if (!Number.isInteger(maxHistory) || maxHistory < 0) {
      throw new Error("maxHistory 必须是非负整数");
    }

    this.present = structuredClone(initialState);
  }

  // 获取当前状态
  getState(): T {
    return structuredClone(this.present);
  }

  // 更新状态
  setState(updater: T | ((prev: T) => T)): void {
    const prev = this.getState();

    const next =
      typeof updater === "function"
        ? (updater as (prev: T) => T)(prev)
        : updater;

    // 先创建快照，确保克隆失败时不破坏历史
    const snapshot = structuredClone(next);

    // 保存旧状态
    if (this.maxHistory > 0) {
      this.past.push(this.present);

      // 限制历史记录数量
      if (this.past.length > this.maxHistory) {
        this.past.shift();
      }
    }

    this.present = snapshot;

    // 产生新分支，旧的重做历史失效
    this.future = [];
  }

  // 撤销
  undo(): boolean {
    if (!this.canUndo()) return false;

    this.future.push(this.present);
    this.present = this.past.pop()!;

    return true;
  }

  // 重做
  redo(): boolean {
    if (!this.canRedo()) return false;

    this.past.push(this.present);
    this.present = this.future.pop()!;

    return true;
  }

  canUndo(): boolean {
    return this.past.length > 0;
  }

  canRedo(): boolean {
    return this.future.length > 0;
  }
}
```

## 其他实现方式
有，而且这是很重要的加分点

|方案|原理|适用场景|
|---|---|---|
|双栈快照|保存每次修改后的完整状态|表单、简单编辑器|
|历史数组 + 指针|历史记录不出栈，只移动索引|时间旅行调试|
|命令模式|保存 `execute` 和 `undo` 行为|绘图软件、复杂编辑器|
|Patch / Diff|只记录每次变化的部分|大对象、复杂状态树|
