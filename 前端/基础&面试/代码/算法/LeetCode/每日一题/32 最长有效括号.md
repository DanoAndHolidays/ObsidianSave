# 32 最长有效括号

#困难 

有点滑动窗口的意味在里面

```java
class Solution {
    public int longestValidParentheses(String s) {
        int leftNum = 0, rightNum = 0, maxLength = 0, n = s.length();

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '(') {
                leftNum++;
            } else {
                rightNum++;
            }

            if (leftNum == rightNum) {
                maxLength = Math.max(maxLength, leftNum + rightNum);
            } else if (rightNum > leftNum) {
                leftNum = 0;
                rightNum = 0;
            }

        }
```

/写到这里，有一种情况是过不了的，"(()"
左括号从一开始就比右括号多，这实际上是因为无法剔除不合法的左括号导致的
使用栈的话，会因为与右括号匹配弹出而留下不合法的左括号，但是我们这里判断不出来

解决的方法也很简单，我们只需要从右往左遍历用类似的方法计算即可，只是这个时候判断条件反了过来

```java
        leftNum = rightNum = 0;

        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') {
                leftNum++;
            } else {
                rightNum++;
            }

            if (leftNum == rightNum) {
                maxLength = Math.max(maxLength, leftNum + rightNum);
            } else if (rightNum < leftNum) {
                leftNum = 0;
                rightNum = 0;
            }

        }

        return maxLength;
    }
}
```
