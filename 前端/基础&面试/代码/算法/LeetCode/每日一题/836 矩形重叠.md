#简单

根据数学知识我们可以知道，当 `min(rec1[2], rec2[2]) > max(rec1[0], rec2[0])` 时，这两条线段有交集:
```ts
var isRectangleOverlap = function(rec1, rec2) {
    return (
        Math.min(rec1[2], rec2[2]) > Math.max(rec1[0], rec2[0]) &&
        Math.min(rec1[3], rec2[3]) > Math.max(rec1[1], rec2[1])
    );
};
```
