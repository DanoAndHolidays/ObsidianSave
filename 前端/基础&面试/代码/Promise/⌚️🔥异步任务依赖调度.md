# ⌚️🔥异步任务依赖调度
> Last Format Time：9/16/2026 19:24:50

一个异步任务可能依赖其他任务，只有当它的所有依赖任务都执行完成后，当前任务才能拿到依赖结果并执行自己的逻辑。

整体流程：
```text
依赖任务
↓
获取每个依赖的 Promise
↓
Promise.all 等待全部完成
↓
拿到所有依赖结果
↓
调用 derive(...results)
↓
得到当前任务自己的 Promise
```

核心代码：
```ts
const promise = Promise.all(
  dependencies.map(task => task.promise)
).then(results => {
  return derive(
    ...(results as TaskResults<Dependencies>)
  );
});
```

---
## AsyncTask 的作用
`AsyncTask<Result>` 表示一个异步任务。

```ts
class AsyncTask<Result> {
  readonly name: string;
  readonly promise: Promise<Result>;
  readonly dependencies: readonly AsyncTask<unknown>[];
}
```

它保存三个东西：

```text
name
任务名称

dependencies
当前任务依赖了哪些任务

promise
当前任务最终执行结果
```

其中最重要的是：

```ts
promise: Promise<Result>
```

每个任务都会暴露自己的 Promise，其他任务通过这个 Promise 等待它完成。

---
## TaskResults 是做什么的
```ts
type TaskResults<
  Dependencies extends readonly AsyncTask<unknown>[],
> = {
  [Index in keyof Dependencies]:
    Dependencies[Index] extends AsyncTask<infer Result>
      ? Result
      : never;
};
```

它的作用是：

> 根据任务依赖列表，自动推导每个任务对应的结果类型。

例如：

```ts
const dependencies = [
  AsyncTask<number>,
  AsyncTask<string>
];
```

那么：

```ts
TaskResults<typeof dependencies>
```

得到：

```ts
[number, string]
```

也就是说：

```text
AsyncTask<number> → number
AsyncTask<string> → string
```

这里：

```ts
infer Result
```

表示从：

```ts
AsyncTask<Result>
```

里面把 `Result` 类型提取出来。

---
## dependencies.map() 得到的不是结果
容易犯的错误：

```ts
const results = dependencies.map(
  dependency => dependency.promise
);
```

这里得到的是：

```ts
Promise<T>[]
```

而不是：

```ts
T[]
```

例如：

```ts
[
  Promise<number>,
  Promise<string>
]
```

因此不能直接把它交给 `derive`。

需要：

```ts
Promise.all(...)
```

把：

```ts
[
  Promise<number>,
  Promise<string>
]
```

转换成：

```ts
Promise<[number, string]>
```

等所有 Promise 完成以后，才能拿到：

```ts
[number, string]
```

---
## Promise.all 的作用
```ts
Promise.all([
  promiseA,
  promiseB
])
```

只有当：

```text
promiseA 完成
+
promiseB 完成
```

之后，才会进入：

```ts
.then(results => {})
```

例如：

```ts
Promise.all([
  Promise.resolve(10),
  Promise.resolve("hello")
])
```

最终结果：

```ts
[10, "hello"]
```

这非常适合处理：

> 当前任务依赖多个异步任务。

---
## 为什么是 derive(...results)
`derive` 的定义：

```ts
derive: (
  ...dependencyResults: TaskResults<Dependencies>
) => Result | Promise<Result>
```

这里用了：

```ts
...
```

表示 rest parameters（剩余参数）。

因此如果依赖结果是：

```ts
[10, 20]
```

应该调用：

```ts
derive(10, 20)
```

而不是：

```ts
derive([10, 20])
```

所以需要：

```ts
derive(...results)
```

这里的 `...` 是 spread operator（展开运算符）。

---
## 当前任务的 Promise 从哪里来
当前任务本身也是异步任务，因此也必须有：

```ts
Promise<Result>
```

所以：

```ts
const promise = Promise
  .all(...)
  .then(...);
```

这个 Promise 就是当前任务自己的 Promise。

然后：

```ts
return new AsyncTask(
  name,
  dependencies,
  promise
);
```

而不是传：

```ts
() => {}
```

因为构造函数要求的是：

```ts
Promise<Result>
```

不是函数。

---
## 完整实现
```ts
class AsyncTaskGraph {
  create<
    Dependencies extends readonly AsyncTask<unknown>[],
    Result,
  >(
    name: string,
    dependencies: Dependencies,
    derive: (
      ...dependencyResults: TaskResults<Dependencies>
    ) => Result | Promise<Result>,
  ): AsyncTask<Result> {

    const promise = Promise
      .all(
        dependencies.map(task => task.promise)
      )
      .then(results => {
        return derive(
          ...(results as TaskResults<Dependencies>)
        );
      });

    return new AsyncTask(
      name,
      dependencies,
      promise
    );
  }
}
```

## 任务依赖关系示例
例如：

```ts
const a = graph.create(
  "A",
  [],
  () => 10
);

const b = graph.create(
  "B",
  [],
  () => 20
);

const c = graph.create(
  "C",
  [a, b] as const,
  (aResult, bResult) => {
    return aResult + bResult;
  }
);
```

依赖关系：

```text
A ───┐
     ├──→ C
B ───┘
```

执行过程：

```text
A.promise → 10
                \
                 Promise.all
                /
B.promise → 20
                ↓
           [10, 20]
                ↓
         derive(10, 20)
                ↓
               30
                ↓
            C.promise
```

---
## Promise 本身就可以承担任务调度
这种题不一定需要自己写一个复杂的调度器。

每个任务只需要：

```ts
Promise.all(自己的依赖)
  .then(执行自己)
```

依赖关系就会自然形成一个 DAG：

```text
A ──→ C ──→ E
B ──→ C

D ────────→ E
```

当 C 等待 A、B：

```ts
Promise.all([
  A.promise,
  B.promise
])
```

E 再等待 C、D：

```ts
Promise.all([
  C.promise,
  D.promise
])
```

整个任务图就可以自动按照依赖顺序执行。

---
## 错误传播
如果某个依赖失败：

```ts
A.promise
```

发生 reject，那么：

```ts
Promise.all([
  A.promise,
  B.promise
])
```

也会 reject。

因此：

```ts
derive(...)
```

不会执行。

错误会自然沿着依赖链继续向后传播。

---
## 这道题主要考什么
核心知识点：

```text
1. Promise.all
   等待多个异步依赖完成

2. Promise 链
   用 then 构建任务依赖关系

3. spread / rest
   derive(...results)

4. TypeScript 泛型
   保留任务结果类型

5. infer
   从 AsyncTask<Result> 中提取 Result

6. tuple 类型
   保证依赖结果和依赖任务一一对应
```

---
## 最重要的模板
以后看到：

> 一个任务依赖多个异步任务，等它们全部完成后再执行。

第一反应：

```ts
Promise.all(
  dependencies.map(dep => dep.promise)
).then(results => {
  return derive(...results);
});
```

一句话记忆：

> **任务依赖调度 = `Promise.all(依赖 Promise) + then(执行当前任务)`。**

这题你重点记最后那个模板就行，类型体操反而是第二层。
