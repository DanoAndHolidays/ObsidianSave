[2333. 最小差值平方和](https://leetcode.cn/problems/minimum-sum-of-squared-difference/)

思路完全正确，这道题的核心就是贪心：每次优先减小当前最大的绝对差值
```java
class Solution {
    public long minSumSquareDiff(int[] nums1, int[] nums2, int k1, int k2) {
        // 本质是 n 个数的平方和，nums1[i] - nums2[i] 的绝对值越小
        // 总和越小，至于加谁，减谁，我们并不在乎，我们肯定可以使其减小

        // 所以就是 |nums1[i] - nums2[i]| 上面去减，优先减值最大的，这是个贪心

        int n = nums1.length;
        int k = k1 + k2;

        System.out.println("n: " + n + " k: " + k);

        int[] arr = new int[n];
        for(int i=0;i< n;i++){
            int num1 = nums1[i];
            int num2 = nums2[i];

            arr[i] = Math.abs(num1 - num2);
        }

        System.out.println("arr: " + Arrays.toString(arr));

        return n;
    }
}
```

但是怎么去在每次操作后，选最大的数

原来最大的数不一定还是最大的，所以需要动态选择

如果直接使用大根堆 `PriorityQueue`：

- 每次取出最大差值
- 减小 1
- 重新放入堆
- 重复 `k` 次

时间复杂度是：`O(n + k log n)`

但是这道题的 `k1 + k2` 可能达到 \(10^9\) 级别，会超时

使用==计数数组==优化贪心：
```text
arr = [5, 5, 3, 1]

差值  频率
 1     1
 3     1
 5     2
```

注意这里的实现，就是 int 的范围，这里的数巨大无比
```java
class Solution {
    public long minSumSquareDiff(int[] nums1, int[] nums2, int k1, int k2) {
        int n = nums1.length;
        long k = (long) k1 + k2;
        int[] arr = new int[n];
        int max = 0;
		long ans = 0;

        for (int i = 0; i < n; i++) {
            arr[i] = Math.abs(nums1[i] - nums2[i]);
            max = Math.max(max, arr[i]);
        }

        // freq[d] 表示差值为 d 的元素数量
        long[] freq = new long[max + 1];

        for (int d : arr) {
            freq[d]++;
        }

        // 从最大的差值开始处理
        for (int d = max; d > 0 && k > 0; d--) {

            // 最多将 freq[d] 个元素各减小 1
            long count = Math.min(k, freq[d]);

            freq[d] -= count;
            freq[d - 1] += count;

            k -= count;
        }
        
        for (int d = 1; d <= max; d++) {
		    // 注意转类型，不然就溢出了
            ans += (long) d * d * freq[d];
        }

        return ans;
    }
}
```
