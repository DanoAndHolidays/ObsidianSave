这道题的思路：既然要去除前后缀，剩下的肯定是子数组，那么就不去关心前后缀，我只关心子数组，进行一个逆向思维

移除的是 nums 最左边或最右边的元素，那么剩下的元素是什么？是 nums 的连续子数组。移除的元素和 x + 剩余的元素和 = nums 的所有元素之和 s。

所以剩余的元素和 = s−x。

问题变成从 nums 中找最长的子数组（这样移除的数尽量少），满足子数组的元素和恰好等于 s−x。

```ts
function minOperations(nums: number[], x: number): number {
    const n = nums.length
    let ans = -1
    const target = nums.reduce((acc, cur) => acc + cur) - x
    console.log(target) 

    let left = 0
    let sum = 0

    for(let right = 0; right < n; right++){
        sum += nums[right]
        while(target < sum){
            sum -= nums[left]
            left ++
        }

        if(target === sum) ans = Math.max(ans, right - left + 1)
        
    }

    return ans === -1 ? -1 : n - ans
};
```
