# 2009 使数组连续的最少操作数
> Last Format Time：10/6/2026 02:27:25

[https://leetcode.cn/problems/minimum-number-of-operations-to-make-array-continuous/submissions/750259018/](https://leetcode.cn/problems/minimum-number-of-operations-to-make-array-continuous/submissions/750259018/)

这里最tm坑的就是：
```ts
nums.sort(((a, b) => a - b))
console.log(nums)

nums.sort()
console.log(nums)
// [ 1, 2, 3, 10, 20 ]
// [ 1, 10, 2, 20, 3 ]
```

不写回调是按第一个数排位的，靠。在 JavaScript 里，`nums.sort()` 默认不是按数值大小排序，而是会先把元素==当成字符串==，再按==字典序==比较

先别想“哪些杯子要移动”，反过来想，我选一个最终的连续区间，原来的杯子有多少已经在里面？

最少移动
↓
最多保留
↓
找最多的原编号，
能够塞进 N 个连续整数中
↓
排序 + 最长合法滑动窗口

```ts
function minMoves(arr: number[]): number {
    const n = arr.length

    arr.sort((a, b) => a - b)

    let left = 0
    let maxKeep = 0

    for (let right = 0; right < n; right++) {

        // 当前这些数字跨度太大，
        // 不可能同时放进 n 个连续编号中
        while (arr[right] - arr[left] > n - 1) {
            left++
        }

        // 当前窗口里的杯子都可以不移动
        maxKeep = Math.max(
            maxKeep,
            right - left + 1
        )
    }

    // 剩下的杯子全部需要移动
    return n - maxKeep
}
```
