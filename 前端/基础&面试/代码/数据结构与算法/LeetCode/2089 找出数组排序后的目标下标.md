[2089. 找出数组排序后的目标下标](https://leetcode.cn/problems/find-target-indices-after-sorting-array/)

```ts
function targetIndices(nums: number[], target: number): number[] {
    nums.sort((a, b) => a - b);
    const ans = [];
    
    for(let i = 0; i< nums.length; i ++){
        if(nums[i] === target){
            ans.push(i)
        }
    }

    return ans
};
```

O(n) 做法：设 nums 中的小于 target 的元素个数为 less，等于 target 的元素个数为 equal

排序后，相同的数是连续的。等于 target 的第一个数的下标为 less，最后一个数的下标为 less + equal − 1
```java
class Solution {
    public List<Integer> targetIndices(int[] nums, int target) {
        int less = 0;
        int equsl = 0;
		
        for (int x : nums) {
            if (x < target) {
                less++;
            } else if (x == target) {
                equsl++;
            }
        }
		
        List<Integer> ans = new ArrayList<Integer>(equsl);
		
        for (int i = 0; i < equsl; i++) {
            ans.add(less + i);
        }
		
        return ans;
    }
}
```
