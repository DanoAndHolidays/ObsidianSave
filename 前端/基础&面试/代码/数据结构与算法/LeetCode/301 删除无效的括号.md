# 301 删除无效的括号
> Last Format Time：10/7/2026 22:01:26

[删除无效的括号](https://leetcode.cn/problems/remove-invalid-parentheses/)

Given a string `s` that contains parentheses and letters, remove the minimum number of invalid parentheses to make the input string valid.

[灵神题解](https://leetcode.cn/problems/remove-invalid-parentheses/solutions/4038185/liang-chong-fang-fa-bfs-hui-su-pythonjav-4hya/?envType=daily-question&envId=2026-10-07)

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        // 对于一个合法字符串，有左括号必有对应的右括号
        // 所以我们统计合法的左括号的数量就可以确定最终串的长度
        char[] str = s.toCharArray();

        // 依旧是 blance
        int validLeftParenthese = 0;
        int currentLeftParenthese = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = str[i];
            if (c == '(') {
                validLeftParenthese++;
                currentLeftParenthese++;
            } else if (c == ')' && currentLeftParenthese > 0) {
                currentLeftParenthese--;
            }
        }

        validLeftParenthese -= currentLeftParenthese;

        // 此时我们得到了合法的左括号的数量，此时可以去选位置了
        // 选validLeftParenthese个左括号和同样数量的右括号

        List<String> ans = new ArrayList<>();
        StringBuilder path = new StringBuilder();
        dfs(0, 0, 0, ans, path, str, validLeftParenthese);
        return ans;
    }

    // 当前枚举到 s[i]，已选 left 个左括号和 right 个右括号
    private void dfs(int i, int left, int right, List<String> ans, StringBuilder path, char[] s, int target) {
        int n = s.length;

        // 剪枝（最后一个判断条件是剩余字符个数不足以让我们选出 target*2 个括号）
        if (left < right || left > target || left + right + n - i < target * 2) {
            return;
        }

        if (i == n) { // 上面剪枝了，这里一定选了 target 个左右括号
            ans.add(path.toString());
            return;
        }

        char ch = s[i];

        // 不选
        if (ch == '(' || ch == ')') {
            // 后面所有等于 ch 的括号都不选
            // 如果不跳过这些括号，会导致「选 ch1 不选 ch2」和「不选 ch1 选 ch2」这两种情况都会加到 ans 中，这就重复了
            int j = i + 1;
            while (j < n && s[j] == ch) {
                j++;
            }
            dfs(j, left, right, ans, path, s, target);
        }

        // 选 ch
        if (ch == '(') {
            left++;
        } else if (ch == ')') {
            right++;
        }
        path.append(ch);
        dfs(i + 1, left, right, ans, path, s, target);
        path.deleteCharAt(path.length() - 1); // 恢复现场
    }
}
```
