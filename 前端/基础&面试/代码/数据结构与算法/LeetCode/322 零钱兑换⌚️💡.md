## 题目描述
有 `n` 组商品，每组包含 `m` 个商品，每个商品都有对应的价格。

规定：

- 每组商品必须整体购买，不能只购买其中一部分。
- 每组商品最多购买一次。
- 可以选择任意多个商品组。
- 总购买金额必须大于等于 `threshold`。
- 求满足条件的最小购买金额。
- 如果无法达到最低消费金额，输出 `-1`。

注：这是根据前面的代码和讨论还原的题意，并非原题的逐字描述。

### 输入示例
```
3 12
1 4
2 3 4
2 5 3
```

第一行的 `3` 表示商品组数量，`12` 表示最低消费金额。

随后每行第一个数表示该组的商品数量，后面的数字是商品价格。

因此，可以先预处理成：
```
prices = [4, 7, 8];
threshold = 12;
```

### 输出示例
```
12
```

因为：
```
4 + 7 = 11  不满足
4 + 8 = 12  最优解
7 + 8 = 15  满足但不是最优
4 + 7 + 8 = 19
```

## 解题思路
背包问题的本质是：从若干物品中选择一部分，在一定约束下，使目标最优。

本题中：

| 背包要素    | 对应内容          |
| ------- | ------------- |
| 物品      | 每组商品          |
| 物品重量/花费 | 该组商品的总价格      |
| 目标门槛    | `threshold`   |
| 选择限制    | 每组只能选择一次      |
| 优化目标    | 满足门槛的最小实际消费金额 |

因为每组商品最多选择一次，所以属于 0/1 背包问题。

注意，这里虽然输入数据按商品组组织，但每组要么全部购买、要么不购买，因此预处理后，每组就是一个独立物品，并不是算法分类中的“分组背包”。

### DP 状态定义
本题的目标不是恰好凑到 `threshold`，而是达到或超过 `threshold`，同时最小化实际总价。

定义：
```
dp[j] = 至少凑出 j 元时，能够实现的最小实际总价
```

例如：
```
dp[10] = 11
```

表示至少消费 10 元，最少需要实际消费 11 元。

初始化：
```
const dp = new Array(threshold + 1).fill(Infinity);
dp[0] = 0;
```

`Infinity` 表示目前无法达到对应金额的要求；`dp[0] = 0` 表示至少消费 0 元时，不购买任何商品即可满足。

---
### 状态转移
假设当前商品组价格为 `price`，对于目标金额 `j`，有两种选择。

不选择当前商品组：
```
dp[j]
```

选择当前商品组：购买它之后，剩余需要达到的金额为：
```
j - price
```

但这个值可能小于 0，因此需要限制：
```
Math.max(0, j - price)
```

对应的实际总价为：
```
dp[Math.max(0, j - price)] + price
```

代码：
```
dp[j] = Math.min(
    dp[j],
    dp[Math.max(0, j - price)] + price
);
```

这里 `Math.max(0, ...)` 非常关键，因为本题允许超过消费门槛。

例如价格只有 `9`，门槛为 `8`，那么购买 9 元的商品就能满足要求，答案应为 9。

### 倒序遍历
```
for (const price of prices) {
    for (let j = threshold; j >= 1; j--) {
        dp[j] = Math.min(
            dp[j],
            dp[Math.max(0, j - price)] + price
        );
    }
}
```

在更新 `dp[j]` 时，需要读取下标更小的状态。

- 正序遍历： 下标更小的状态可能已经使用了当前商品，导致重复选择。
- 倒序遍历： 下标更小的状态尚未被本轮更新，保证当前商品最多使用一次。

## 完整参考代码（JavaScript / Node.js）
```
const rl = require("readline").createInterface({
    input: process.stdin
});

const iter = rl[Symbol.asyncIterator]();
const readline = async () => (await iter.next()).value;

void (async function () {
    const [n, threshold] = (await readline())
        .trim()
        .split(/\s+/)
        .map(Number);

    const prices = [];

    // 1. 预处理：计算每组商品的总价
    for (let i = 0; i < n; i++) {
        const tokens = (await readline())
            .trim()
            .split(/\s+/)
            .map(Number);

        const m = tokens[0];

        const priceSum = tokens
            .slice(1, m + 1)
            .reduce((sum, num) => sum + num, 0);

        prices.push(priceSum);
    }

    // 2. DP 初始化
    // dp[j]：达到至少 j 元所需的最小实际总价
    const dp = new Array(threshold + 1).fill(Infinity);
    dp[0] = 0;

    // 3. 0/1 背包：倒序遍历
    for (const price of prices) {
        for (let j = threshold; j >= 1; j--) {
            dp[j] = Math.min(
                dp[j],
                dp[Math.max(0, j - price)] + price
            );
        }
    }

    // 4. 输出答案
    console.log(
        dp[threshold] === Infinity ? -1 : dp[threshold]
    );
})();
```

复杂度分析：设 `n` 为商品组数量、`T` 为 `threshold`、`K` 为输入的商品总数。

## 背包问题的通用解题套路

| 类型     | 特征          | 一维 DP 遍历方向  |
| ------ | ----------- | ----------- |
| 0/1 背包 | 每件物品最多选择一次  | 倒序          |
| 完全背包   | 每件物品可以无限选择  | 正序          |
| 多重背包   | 每件物品有固定使用次数 | 通常采用拆分或专门优化 |
| 分组背包   | 每组最多选择一个物品  | 按组处理，容量倒序   |

这里的正序、倒序针对的是以物品为外层、容量为内层的常见一维状态压缩写法。

## 确定 DP 数组的含义

常见的状态定义可以分为四种。

| 题目要求        | 状态定义                   | 初始值                  |
| ----------- | ---------------------- | -------------------- |
| 能否凑出目标      | `dp[j]` 能否恰好凑出 j       | `false`，`dp[0]=true` |
| 凑出目标的最少物品数  | `dp[j]` 恰好凑出 j 的最少件数   | `Infinity`，`dp[0]=0` |
| 容量限制下最大价值   | `dp[j]` 容量不超过 j 时的最大价值 | 通常全部为 `0`            |
| 达到门槛的最小实际总价 | `dp[j]` 至少凑出 j 的最小总价   | `Infinity`，`dp[0]=0` |

状态定义决定了状态转移方程和初始化方式。

尤其注意“恰好达到”“不超过”“至少达到”三个条件并不一样。
