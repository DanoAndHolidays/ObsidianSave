上面的是根据深度的奇偶来分，我们换成深度的大小来分也可以：

function maxDepthAfterSplit(seq: string): number[] {
    const n = seq.length
    const ans = []
    if (n === 0) return ans

    let blance = 0
    let maxBlance = 0
    for(const c of seq){
        if(c === '('){
            blance++
        }else{
            blance--
        }
        maxBlance = Math.max(blance, maxBlance)
    }

    console.log(maxBlance)
    const b = Math.floor(maxBlance / 2)

    blance = 0

    for (const char of seq) {
        if (char === '(') {
            ans.push(blance < b ? 0 : 1)
            blance++
        } else {
            blance--
            ans.push(blance < b ? 0 : 1)
        }
    }

    return ans
};

## 贪心
两个子序列，一个A，一个B。要求是AB的深度尽可能小，那最合理的办法：
1. 遇到左括号，谁的深度小先给谁，让大的别增长那么快
2. 遇到右括号，谁的深度大先给谁，让大的先降下来
3. 遍历的过程中就能知道i应该给A还是给B

```java
class Solution {
    public int[] maxDepthAfterSplit(String seq) {
        char[] cs = seq.toCharArray();
        int blanceA = 0, blanceB = 0, n = cs.length;

        int[] ans = new int[n];
        
        // 因为这个是 VSP 所以不用考虑闭合的问题
        for (int i = 0; i < n; i++) {
            char c = cs[i];
            if (c == '(') {
                if (blanceA < blanceB) {
                    blanceA++;
                    ans[i] = 0;
                } else {
                    blanceB++;
                    ans[i] = 1;
                }
            } else {
                if (blanceA > blanceB) {
                    blanceA--;
                    ans[i] = 0;
                } else {
                    blanceB--;
                    ans[i] = 1;
                }
            }
        }

        return ans;
    }
}
```
