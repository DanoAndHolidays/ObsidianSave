# 规范化规则速查
每条规则配一组 ❌ 反例 / ✅ 正例。整理笔记时按这张表对照。

---
## H1 元信息块
每个 H1 紧跟一行 `> Last Format Time：M/D/YYYY HH:MM:SS`（脚本自动维护）。

❌ **错误**：H1 直接接正文，没有元信息块

```markdown
# 文档标题
由于 http 是无状态的...
```

✅ **正确**：H1 紧跟元信息块

```markdown
# 文档标题
> Last Format Time：6/12/2026 19:19:42 

由于 http 是无状态的...
```

❌ **错误**：元信息块与 H1 之间有空行

```markdown
# 文档标题

> Last Format Time：6/12/2026 19:19:42 
```

✅ **正确**：H1 与元信息块紧邻

```markdown
# 文档标题
> Last Format Time：6/12/2026 19:19:42 
```

**H1 下方有外部链接**：

```markdown
# Fetch API
> Last Format Time：6/12/2026 19:19:42 

[MDN文档](https://developer.mozilla.org/...)

---
## 二级标题
```

**H1 下方无外部链接 / 引言段落**：

```markdown
# Fetch API
> Last Format Time：6/12/2026 19:19:42 

---
## 二级标题
```

**H1 下方有引言段落**：

```markdown
# Fetch API
> Last Format Time：6/12/2026 19:19:42 

引言段落内容……

---
## 二级标题
```

## 标题层级
允许：**H1 / H2 / H3 / H5**。禁用：H4、H6+。
❌ **错误**：用 H4

```markdown
### 子章节
#### 进一步细分
```

✅ **正确**：跳过 H4，用 H5

```markdown
### 子章节
##### 进一步细分
```

❌ **错误**：标题前加数字标号

```markdown
## 1. 章节一
### 1.1 子章节
```

✅ **正确**：直接用标题

```markdown
## 章节一
### 子章节
```

## 分隔符
**所有 H2 紧上方（不空行）都必须有 `---` 分隔符**，包括首个 H2。无论 H1/meta 与首个 H2 之间是否有链接、引言段落，一律加 `---`。

❌ **错误**：H2 上方缺 `---`

```markdown
# Fetch API
> Last Format Time：6/12/2026 19:19:42 

[MDN文档](https://...)

## 二级标题
```

✅ **正确**：H2 紧上方有 `---`（不空行）

```markdown
# Fetch API
> Last Format Time：6/12/2026 19:19:42 

[MDN文档](https://...)

---
## 二级标题
```

❌ **错误**：H2 跟上面的 `---` 中间有空行

```markdown
正文...

---

## 下一个章节
```

✅ **正确**：`---` 紧跟 H2（不空行）

```markdown
正文...

---
## 下一个章节
```

❌ **错误**：`---` 跟上方正文之间缺空行

```markdown
上一段正文。
---
## 下一个章节
```

✅ **正确**：`---` 上方有一空行（按"正文尾 → 标题间空一行"规则）

```markdown
上一段正文。

---
## 下一个章节
```

## 空行
### 标题后接正文/列表
❌ **错误**：H2 后空一行再接正文

```markdown
## 章节

这是正文。
```

✅ **正确**：H2 紧跟正文

```markdown
## 章节
这是正文。
```

### 列表前
❌ **错误**：正文后空一行再接列表

```markdown
## 章节
正文段落。

- 列表项
```

✅ **正确**：正文后直接接列表

```markdown
## 章节
正文段落。
- 列表项
```

### 列表项之间
❌ **错误**：列表项之间空行

```markdown
- 第一项

- 第二项
```

✅ **正确**：列表项紧跟

```markdown
- 第一项
- 第二项
```

### 上一段结尾 → 下一个标题
❌ **错误**：上一段后直接接标题（没空行）

```markdown
## 章节一
这是上一节的最后一段。
## 章节二
```

✅ **正确**：上一段结尾空一行再接标题

```markdown
## 章节一
这是上一节的最后一段。

## 章节二
```

### 代码块前后
❌ **错误**：描述性文字后多空了一行

```markdown
下面是一段代码：

```javascript
const x = 1;
```
```

✅ **正确**：描述性文字直接引出代码块，不空行

```markdown
下面是一段代码：
```javascript
const x = 1;
```
```

❌ **错误**：独立段落（不直接引出代码）与代码块之间忘了空行

```markdown
上一段独立正文段落。
```javascript
const x = 1;
```
```

✅ **正确**：独立段落与代码块之间空一行

```markdown
上一段独立正文段落。

```javascript
const x = 1;
```
```

### 代码块后接标题
代码块算正文，后面接标题/段落/引用块/代码块都要空一行（接列表除外，可以紧贴）。

❌ **错误**：代码块直接接下一个标题（没空行）

```markdown
```javascript
const x = 1;
```
## 下一节
```

✅ **正确**：代码块后空一行再接标题

```markdown
```javascript
const x = 1;
```

## 下一节
```

## 代码块
❌ **错误**：没指定语言

````
```
const x = 1;
```
````

✅ **正确**：指定合法语言标签

````
```javascript
const x = 1;
```
````

**合法标签**：jsx、tsx、ts、js、javascript、css、scss、html、bash、sh、shell、json、yaml、md、markdown、text。

## 链接
✅ 内部笔记用 `[[双链]]`：

```markdown
看 [[useHandler ⌚️🌟]] 这篇笔记。
```

✅ 外部资源用标准链接（脚本会把 H1 下的裸 URL 自动包成 `[URL](URL)`）：

```markdown
参考 [React 官方文档](https://react.dev)。
```

## 例外说明
任何规则都允许例外，例外必须用斜体说明原因。

```markdown
## 标准化的标题

*原标题：xxx，因为要保持命名一致性*

## 规范后的标题
```
