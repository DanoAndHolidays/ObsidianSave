# 规范化规则速查
每条规则配一组 ❌ 反例 / ✅ 正例。整理笔记时按这张表对照。

---
## 标题层级
允许：**H1 / H2 / H3 / H5**。禁用：H4、H6+。
❌ **错误**：用 H4

```markdown
### 子章节
#### 进一步细分
```

✅ **正确**：跳过 H4，用 H5

```markdown
### 子章节
##### 进一步细分
```

❌ **错误**：标题前加数字标号

```markdown
## 1. 章节一
### 1.1 子章节
```

✅ **正确**：直接用标题

```markdown
## 章节一
### 子章节
```

## 分隔符
❌ **错误**：H1 跟第一个 H2 之间加了 `---`（中间有引言）

```markdown
# 标题
引言...

---

## 第一个章节
```

✅ **正确**：H1 跟第一个 H2 之间有正文时加 `---`（紧跟 H2）

```markdown
# 标题
引言...

---
## 第一个章节
```

❌ **错误**：H2 跟上面的 `---` 中间有空行

```markdown
正文...

---

## 下一个章节
```

✅ **正确**：`---` 紧跟 H2（不空行）

```markdown
正文...

---
## 下一个章节
```

## 空行
### 标题后接正文/列表
❌ **错误**：H2 后空一行再接正文

```markdown
## 章节

这是正文。
```

✅ **正确**：H2 紧跟正文

```markdown
## 章节
这是正文。
```

### 列表前
❌ **错误**：正文后空一行再接列表

```markdown
## 章节
正文段落。

- 列表项
```

✅ **正确**：正文后直接接列表

```markdown
## 章节
正文段落。
- 列表项
```

### 列表项之间
❌ **错误**：列表项之间空行

```markdown
- 第一项

- 第二项
```

✅ **正确**：列表项紧跟

```markdown
- 第一项
- 第二项
```

### 上一段结尾 → 下一个标题
❌ **错误**：上一段后直接接标题（没空行）

```markdown
## 章节一
这是上一节的最后一段。
## 章节二
```

✅ **正确**：上一段结尾空一行再接标题

```markdown
## 章节一
这是上一节的最后一段。

## 章节二
```

### 代码块前后
❌ **错误**：代码块前没空行（且前面不是标题/列表）

```markdown
正文段落。
```javascript
const x = 1;
```
```

✅ **正确**：代码块前空一行

```markdown
正文段落。

```javascript
const x = 1;
```
```

## 代码块
❌ **错误**：没指定语言

````
```
const x = 1;
```
````

✅ **正确**：指定合法语言标签

````
```javascript
const x = 1;
```
````

**合法标签**：jsx、tsx、ts、js、javascript、css、scss、html、bash、sh、shell、json、yaml、md、markdown、text。

## 链接
✅ 内部笔记用 `[[双链]]`：

```markdown
看 [[useHandler ⌚️🌟]] 这篇笔记。
```

✅ 外部资源用标准链接：

```markdown
参考 [React 官方文档](https://react.dev)。
```

## 例外说明
任何规则都允许例外，例外必须用斜体说明原因。

```markdown
## 标准化的标题

*原标题：xxx，因为要保持命名一致性*

## 规范后的标题
```
