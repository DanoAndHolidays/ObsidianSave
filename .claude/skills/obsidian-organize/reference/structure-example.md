## 第二个章节
每个 H2 紧上面（不空行）有一个 `---` 分隔符。H2 紧跟正文（不空行）。
### 带代码块的子章节
代码块的空行规则：前面是描述性文字（如"这里举例："）时不空行；后面接正文时空一行。这里举例：
```tsx
import { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(c => c + 1)}>{count}</button>;
};
```

代码块下面是正文，前后空一行保持可读。

### 带列表的子章节
列表前不空行，列表后空一行再接下一段：
- 列表项 A
- 列表项 B
- 列表项 C

上面列表结束后空一行再接这段正文。

### 嵌套列表
列表里可以嵌套子列表：
1. 第一项
2. 第二项
    - 嵌套 A
    - 嵌套 B
3. 第三项

数字列表和 `-` 列表都可以。
