# 表选项
```MySQL
CREATE TABLE activity (
    ...
) ENGINE=InnoDB
  DEFAULT CHARSET=utf8mb4
  COLLATE=utf8mb4_0900_ai_ci;
```

- `ENGINE=InnoDB`：指定存储引擎，支持事务、行级锁、外键等。

- `DEFAULT CHARSET=utf8mb4`：指定表的默认字符集，支持完整 Unicode，包括 Emoji。

- `COLLATE=utf8mb4_0900_ai_ci`：指定表的默认排序规则。
    
    - `0900`：基于 Unicode 9.0.0。
    - `ai`：不区分重音。
    - `ci`：不区分大小写。

补充： `utf8mb4_0900_ai_ci` 是 MySQL 8.0 引入的排序规则，也是 MySQL 8.0 中 `utf8mb4` 的默认排序规则。MySQL 5.7 不支持它。

对于你的 SideBy 项目，如果使用 MySQL 8.0，当前这一行配置是很常见且合理的，不需要特意修改。
