Spring 启动时，会先扫描并创建各种对象，放进 IoC 容器：
```java
@Service
public class DeptServiceImpl implements DeptService {
}
```

`@Service` 会让 `DeptServiceImpl` 被 Spring 管理：
```java
@Autowired
private DeptService deptService;
```

Spring 会根据 `DeptService` 类型，从 IoC 容器中寻找可以注入的 Bean：
```text
DeptService
    ↑
DeptServiceImpl
```

如果只有一个实现：
```text
@Autowired DeptService
        ↓
找到 DeptServiceImpl
        ↓
注入
```

注意：不是执行到 `@Autowired` 时才去扫描代码，而是 **Bean 已经提前注册进 IoC 容器，注入时从容器中匹配**。

多个实现类例如：
```java
@Service
public class AServiceImpl implements DeptService {}

@Service
public class BServiceImpl implements DeptService {}
```

此时：
```java
@Autowired
private DeptService deptService;
```

Spring 按类型发现两个 Bean，不知道选谁，通常会报：
```text
NoUniqueBeanDefinitionException
```

可以用：
```java
@Primary
@Service
public class AServiceImpl implements DeptService {}
```

表示默认优先使用它，或者：
```java
@Autowired
@Qualifier("aServiceImpl")
private DeptService deptService;
```

可以记：
- `0 个 Bean` → 找不到，注入失败
- `1 个 Bean` → 自动注入
- `多个 Bean` → 通常无法确定，报错
- `@Primary` → 设置默认 Bean
- `@Qualifier` → 指定具体 Bean

## Bean
Bean 就是由 Spring IoC 容器创建、管理的 Java 对象

Spring 中：
```java
@Service
public class DeptServiceImpl {
}
```

对象由 Spring 创建：
```text
Spring
 ↓
创建 DeptServiceImpl
 ↓
放进 IoC 容器
 ↓
这个对象就是 Bean
```

Bean 通常产生：
```java
@Component
@Service
@Repository
@Controller
@RestController
```

这些注解都可以让对应类被 Spring 扫描并注册为 Bean，还有一种：
```java
@Configuration
public class Config {

    @Bean
    public UserService userService() {
        return new UserService();
    }
}
```

这里 `@Bean` 方法返回的对象也会交给 Spring 管理。

所以：
```text
@Component / @Service / @Controller ...
                ↓
         Spring 自动扫描

@Bean
 ↓
手动声明要交给 Spring 的对象

最终
 ↓
IoC 容器中的 Bean
```

Bean = Spring 管理的对象
IoC 容器 = 存放、创建、管理 Bean 的地方
DI（依赖注入）= Spring 把需要的 Bean 塞给另一个 Bean

例如：
```java
@RestController
public class DeptController {

    private final DeptService deptService;

    public DeptController(DeptService deptService) {
        this.deptService = deptService;
    }
}
```

可以理解为：
```text
Spring IoC 容器

DeptServiceImpl Bean
        ↓
        ↓ 注入
        ↓
DeptController Bean
```
