## SQL设计
```sql
 -- 出现分组字段后，只可以使用分组字段，和聚合函数
SELECT
  (CASE job WHEN 1 THEN '火箭部部长' WHEN 2 THEN '飞机部部长' ELSE '保洁' END) pos,
  COUNT(*) num
FROM
  emp
GROUP BY
  job
ORDER BY
  num


 -- 出现分组字段后，只可以使用分组字段，和聚合函数
SELECT
  (CASE WHEN job = 1 THEN '火箭部部长' WHEN job = 2 THEN '飞机部部长' ELSE '保洁' END) pos,
  COUNT(*) num
FROM
  emp
GROUP BY
  job
ORDER BY
  num
```

问题出在 `GROUP BY job` 现在的 `pos` 是这样算出来的：
```text
CASE WHEN job = 1 THEN '火箭部部长'
     WHEN job = 2 THEN '飞机部部长'
     ELSE '保洁'
END
```

但你分组用的是 `job`，不是 `pos` 所以数据库实际上是在按 **每个不同的 job 值** 分组，然后把这些不同的 job 映射成同一个 `pos`

```sql
SELECT
  IF(gender = 1,'男','女') name,
  COUNT(*) value
FROM
  emp
GROUP BY
  gender
```
