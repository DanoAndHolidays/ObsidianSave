[form 的 enctype 属性](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/form#enctype)

当 `method` 属性值为 `post` 时，`enctype` 就是将表单的内容提交给服务器的 [MIME 类型](https://zh.wikipedia.org/wiki/%E4%BA%92%E8%81%94%E7%BD%91%E5%AA%92%E4%BD%93%E7%B1%BB%E5%9E%8B "外部链接（在新标签页中打开）")。可能的取值有：
- `application/x-www-form-urlencoded`：未指定属性时的默认值。
- `multipart/form-data`：当表单包含 `type=file` 的 [`<input>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/input) 元素时使用此值。
- `text/plain`：出现于 HTML5，用于调试。这个值可被 [`<button>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/button)、[`<input type="submit">`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/input/submit) 或 [`<input type="image">`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/input/image) 元素上的 [`formenctype`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/button#formenctype) 属性覆盖。

很关键的点：
- 使用 ==post== 方法
- 必须使用 ==multipart/form-data== 编码，不使用的话，默认是 ==application/x-www-form-urlencoded== 可以看到，默认只有文件的名字，使用 multipart/form-data 后就会变成二进制![[Pasted image 20260922234903.png]]![[Pasted image 20260922234923.png]]使用火狐浏览器就可以看到二进制的内容空：![[Pasted image 20260922235928.png]]

示例：
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>upload</title>
</head>
<body>
<form action="/upload" method="post" enctype="multipart/form-data">
    <input type="text" name="name">
    <input type="text" name="age">
    <input type="file" name="file">
    <button type="submit">submit</button>
</form>
</body>
</html>
```

```java
@Slf4j
@RequestMapping("/upload")
@RestController
public class UploadController {
    @PostMapping
    public Result upload(String name, Integer age, MultipartFile file) throws IOException {
        log.info("接受到的参数： {},{},{}", name, age, file);

        file.transferTo(new File("G:\\Save\\Grogramming\\Java\\web-ai-heima\\tlias-web-management\\src\\main\\resources\\static\\" + UUID.randomUUID() + file.getOriginalFilename().substring(file.getOriginalFilename().lastIndexOf("."))));
        return Result.success();
    }
}
```

如果文件太大会上传不上去（Spring 默认 1MB），需要更改配置文件中上传限制：
```yml
spring:
  servlet:
    multipart:
      # 单个文件
      max-file-size: 10MB
      # 表单整体的大小限制
      max-request-size: 100MB
```
