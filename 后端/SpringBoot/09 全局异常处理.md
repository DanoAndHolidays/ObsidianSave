## 全局异常处理器
![[Pasted image 20260923212114.png]]

```java
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    // 使用继承链靠下的，子类优先
    @ExceptionHandler
    public Result handleException(Exception e){
        log.error("程序出错", e);
        return Result.error("程序出错");
    }

    @ExceptionHandler
    public Result handleDuplicateKeyException(DuplicateKeyException duplicateKeyException){
        int index = duplicateKeyException.getMessage().indexOf("Duplicate entry");
        return Result.error(duplicateKeyException.getMessage().substring(index).split(" ")[2] + "已重复");
    }
}
```

AOP（面向切面编程）是一种将日志、事务、权限校验、缓存等横切关注点从业务代码中分离出来的编程思想。在 Spring 中，AOP 主要通过**动态代理**实现：Spring 为目标对象创建代理对象，在方法执行前后或执行过程中插入增强逻辑，而无需修改业务代码。其核心概念包括 **Aspect（切面）**、**Advice（通知）**、**Pointcut（切点）** 和 **Join Point（连接点）**。实际开发中，`@Transactional`、统一日志、权限校验、接口耗时统计等功能都大量依赖 AOP。
