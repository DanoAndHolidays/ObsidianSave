## 不可变设计
使用 final 来修饰属性和类

==属性==用 final 修饰保证了该属性是只读的，不能修改
==类==用 final 修饰保证了该类中的方法不能被覆盖，防止子类无意间破坏不可变性

## 享元模式
对于数据一致的同类型的对象，我们可以共享他们，不用创建新的，直接==复用旧的==

包装类的 valueOf 就使用了享元模式：
```java
@IntrinsicCandidate  
public static Long valueOf(long l) {  
    final int offset = 128;  
    if (l >= -128 && l <= 127) { // will cache  
        return LongCache.cache[(int)l + offset];  
    }  
    return new Long(l);  
}
```
