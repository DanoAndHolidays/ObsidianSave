## DeadLock 死锁
你等我，我等你，永远等不完

```java
Object lockA = new Object();
Object lockB = new Object();

Thread t1 = new Thread(() -> {
    synchronized (lockA) {
        synchronized (lockB) {
            // ...
        }
    }
});

Thread t2 = new Thread(() -> {
    synchronized (lockB) {
        synchronized (lockA) {
            // ...
        }
    }
});
```

### 条件
- 资源互斥
- 持有等待，拿到资源就不放
- 环路等待，你等我，我等你
- 不可抢占，不可以抢夺其他线程的资源

## LiveLock 活锁
两个线程互相改变对方的结束条件，始终无法结束
