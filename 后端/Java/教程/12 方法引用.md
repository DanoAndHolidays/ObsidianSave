# 12 方法引用
> Last Format Time：9/16/2026 19:24:55

和回调函数很像：

- 引用出必须是函数式接口
- 被引用的函数一定是已经存在的
- 被引用的函数的形参与返回值与函数式接口一致

```java
ArrayList<String> list = new ArrayList<>();  
Collections.addAll(list, "1", "22", "333", "7", "8");  
  
list.forEach(s -> System.out.println(s));  
list.forEach(System.out::println);
```

---
## 引用静态方法
```java
类名 :: 静态方法名

ArrayList<String> list = new ArrayList<>();  
Collections.addAll(list, "1", "22", "333", "7", "8");  
  
list.stream().map(Integer::parseInt).forEach(System.out::println);
```

---
## 引用成员方法
```java
对象 :: 成员方法名

ArrayList<String> list = new ArrayList<>();  
Collections.addAll(list, "1", "22", "333", "7", "8");  
  
list.stream().map(Integer::parseInt).forEach(System.out::println);
```

### 引用其他类
```java
其他类对象 :: 成员方法名
```

### 引用本类
[[05 面向对象]]
要注意的是，引用处的位置不能是静态的方法，因为静态方法中没有隐含的 `this` ，可以 `new` 一个本类的对象出来引用方法，这就变成了引用成员方法了：
```java
this :: 方法名
```

### 引用父类
和上面的一样，需要注意静态方法中的问题：
```java
super :: 方法名
```

---
## 引用构造方法
```java
类名 :: new

ArrayList<String> list = new ArrayList<>();  
Collections.addAll(list, "name1,21", "name2,23", "name3,22", "name4,25", "name5,21");  
  
list.stream().map(Student::new).toList().forEach(System.out::println);

// Student{name='name1', age=21}
// Student{name='name2', age=23}
// Student{name='name3', age=22}
// Student{name='name4', age=25}
// Student{name='name5', age=21}
```

## 其他调用方式
### 类名引用成员方法
```java
类名 :: 成员方法名
```

- 引用出必须是函数式接口
- 被引用的函数一定是已经存在的
- 被引用的函数的形参与返回值与函数式接口一致
- 类里面成员方法其实都会有一个隐藏的参数this，所以虚拟机运行的时候就是第一个参数只会是当前类的类型.this
- 就相当于引用方法可以省略第一个参数，默认是Stream流中数据的类型

### 引用数组的构造方法
```java
类型[] :: new

ArrayList<String> list = new ArrayList<>();  
Collections.addAll(list, "name1,21", "name2,23", "name3,22", "name4,25", "name5,21");  
  
String[] array = list.stream().toArray(String[]::new);  
System.out.println(Arrays.toString(array));  
// [name1,21, name2,23, name3,22, name4,25, name5,21]
```
