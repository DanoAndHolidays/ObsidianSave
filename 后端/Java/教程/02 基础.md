## 字面量
**字面量（literal）**是直接写在源代码中的固定数据值。变量是“保存数据的名字”，字面量则是“数据本身的书写形式”。

| 类别 | 含义 | 示例 |
| --- | --- | --- |
| 整数字面量 | 不带小数部分的整数 | `666`、`-88` |
| 浮点数字面量 | 带小数部分的数 | `13.14`、`-5.21` |
| 字符串字面量 | 用双引号包围的字符序列 | `"HelloWorld"`、`"黑马程序员"` |
| 字符字面量 | 用单引号包围且只能有一个字符 | `'A'`、`'0'`、`'我'` |
| 布尔字面量 | 表示真假 | `true`、`false` |
| `null` 字面量 | 表示引用不指向任何对象 | `null` |

`null` 不是一种基本数据类型，也不能赋给 `int`、`boolean` 等基本类型变量；它只能用于引用类型。 *已纠正*

### 转义字符
转义字符以反斜杠 `\` 开头，用来表示特殊字符：

```text
\n  换行
\t  制表符（Tab）
\r  回车
\\  反斜杠
\"  双引号
\'  单引号
```

制表符的实际显示宽度取决于终端或编辑器的制表位设置，不应把它理解成固定数量的空格。 *已补充*

## 变量
变量是内存中一块数据空间的名字。变量必须先声明并赋值，之后才能参与运算或输出。

```java
数据类型 变量名 = 数据值;
```

示例：

```java
int age = 22;
String name = "Dano";

System.out.println(name);
age = age + 1; // 修改变量中保存的值
System.out.println(age);
```

变量的主要用途是：

- 输出数据；
- 参与计算；
- 保存会变化的状态；
- 通过重新赋值记录新值。

### 变量的使用规则
- 同一作用域内，变量名不能重复声明。
- 变量在使用前必须完成赋值。
- 一个语句可以声明多个同类型变量，但实际开发中通常一行声明一个变量，更容易阅读和调试。
- 变量在某个代码块中声明后，通常只能在该作用域及其嵌套作用域中使用。
- 变量只能保存一个值；重新赋值会覆盖旧值。

```java
int a = 10;
// int a = 20; // 同一作用域中重复声明，编译错误

a = 20;        // 重新赋值，合法
```

## Java 数据类型
Java 数据类型分为两大类：

```text
基本数据类型（primitive type）
引用数据类型（reference type）
```

### 基本数据类型：四类八种
| 分类 | 类型 | 取值范围或含义 | 常见字面量注意事项 |
| --- | --- | --- | --- |
| 整数 | `byte` | -128 ～ 127 | 适合很小的整数 |
| 整数 | `short` | -32,768 ～ 32,767 | 业务代码中较少直接使用 |
| 整数 | `int` | -2³¹ ～ 2³¹ - 1 | 整数字面量默认是 `int` |
| 整数 | `long` | -2⁶³ ～ 2⁶³ - 1 | 超出 `int` 范围时使用 `L` 或 `l` |
| 浮点数 | `float` | 约 ±3.4 × 10³⁸，精度约 6～7 位十进制有效数字 | 字面量通常加 `F` 或 `f` |
| 浮点数 | `double` | 约 ±1.8 × 10³⁰⁸，精度约 15 位十进制有效数字 | 浮点数字面量默认是 `double` |
| 字符 | `char` | `\u0000` ～ `\uffff`，即 0 ～ 65,535 | 本质上是无符号 16 位整数，使用单引号 |
| 布尔 | `boolean` | `true` 或 `false` | 不能与整数 `0`、`1` 直接互换 |

整数和浮点数通常可以按表示范围粗略理解为：

```text
double > float > long > int > short > byte
```

这只是选择类型和自动转换时的常用参考，不代表所有类型都能无损转换。例如 `int` 转 `float` 可能损失整数精度，`long` 转 `double` 也可能损失精度。 *已补充*

```java
long population = 8_000_000_000L;
float ratio = 0.5F;
double price = 19.99;
char grade = 'A';
boolean enabled = true;
```

不要把“内存占用 1 字节”当成 `boolean` 的 Java 语言保证。JLS 只规定 `boolean` 的取值和运算语义，并未规定单独 `boolean` 变量必须占用固定字节数。 *已纠正*

### 引用数据类型
引用类型变量保存的是对象的引用，而不是对象本身的全部内容。常见引用类型包括：

- 类：`String`、`Scanner`、自定义类；
- 接口；
- 数组；
- 枚举；
- 注解。

```java
String text = "Java";
int[] numbers = {1, 2, 3};
```

引用变量可以为 `null`，表示当前没有指向对象：

```java
String value = null;
// value.length(); // 运行时会抛出 NullPointerException
```

`String` 虽然写起来像基本数据，但它是类，是引用类型；字符串的 `+` 拼接、不可变性和对象语义要与基本类型区分开。 *已补充*

### 基本类型与包装类型
集合和泛型不能直接使用基本类型，必须使用对应的包装类型：

| 基本类型 | 包装类型 |
| --- | --- |
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

Java 会在需要时进行自动装箱和拆箱，但拆箱 `null` 会抛出 `NullPointerException`：

```java
Integer count = 10; // 自动装箱
int value = count;  // 自动拆箱
```

## 数据在计算机中的表示
从计算机底层看，数据最终都以二进制形式存储和处理：

- 数值通常编码为二进制整数或浮点数；
- 字符通过字符编码表示，Java `char` 使用 UTF-16 代码单元；
- 图片通常由像素组成，每个像素可用 RGB 等通道表示；
- 音频会对声音波形进行采样、量化和编码。

这些底层表示帮助理解“数据为什么有范围”和“为什么会出现精度问题”，但 Java 开发时应优先使用类型和 API 表达业务含义，而不是手动操作底层二进制。

## 标识符
**标识符（identifier）**是类、变量、方法、接口等程序元素的名称。

基本规则：

- 可以包含字母、数字、下划线 `_` 和美元符号 `$`；
- 不能以数字开头；
- 不能使用 Java 关键字或保留字；
- 区分大小写，例如 `name` 与 `Name` 是两个不同标识符；
- 虽然 `$` 在语法上允许，但业务代码中通常不主动使用，避免与编译器生成名称混淆。

常用命名约定：

| 对象 | 命名方式 | 示例 |
| --- | --- | --- |
| 变量、方法 | 小驼峰 | `userName`、`calculateTotal()` |
| 类、接口、枚举 | 大驼峰 | `UserService`、`PaymentStatus` |
| 常量 | 全大写加下划线 | `MAX_RETRY_COUNT` |
| 包 | 全小写，通常使用反向域名 | `com.example.demo` |

命名应优先表达含义，而不是只追求短：`userCount` 通常比 `n` 更容易维护。

## 从键盘读取数据：`Scanner`
`System.in` 是标准输入流，默认从控制台读取原始字节；`Scanner` 可以在其上进一步解析整数、字符串和浮点数。

```java
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        try (Scanner scanner = new Scanner(System.in)) {
            System.out.print("请输入年龄和姓名：");
            int age = scanner.nextInt();
            String name = scanner.next();

            System.out.printf("%s 的年龄是 %d%n", name, age);
        }
    }
}
```

使用步骤：

1. 导入类：`import java.util.Scanner;`；
2. 创建对象：`new Scanner(System.in)`；
3. 调用读取方法，例如 `nextInt()`、`nextDouble()`、`next()` 或 `nextLine()`。

常用方法：

| 方法 | 读取内容 |
| --- | --- |
| `nextInt()` | 下一个整数 |
| `nextDouble()` | 下一个 `double` |
| `next()` | 下一个以空白分隔的 token |
| `nextLine()` | 当前行剩余的完整文本 |
| `hasNextInt()` | 判断下一个 token 能否解析为整数 |

### `nextInt()` 与 `nextLine()` 的常见陷阱
`nextInt()` 通常只消费整数本身，不会消费后面的换行符；紧接着调用 `nextLine()` 可能读到一个空字符串。需要读取整行时，可以先额外调用一次 `nextLine()`，或者统一使用 `nextLine()` 再手动解析。

```java
int age = scanner.nextInt();
scanner.nextLine();       // 消费本行剩余的换行
String address = scanner.nextLine();
```

输入不符合目标类型时，`nextInt()` 等方法可能抛出 `InputMismatchException`。交互式程序应结合 `hasNextInt()` 或异常处理提高健壮性。 *已补充*

`Scanner` 使用完毕后应关闭，但关闭它也会关闭底层的 `System.in`；如果同一个进程后续还要继续读取标准输入，不要在中途关闭共享的 `Scanner`。

Java 程序中还常见：

```java
System.in   // 标准输入
System.out  // 标准输出
System.err  // 标准错误输出
```

## IDEA 项目结构与 Java 代码结构
下面这组关系常用于理解 IDEA 中的工程：

```text
Project（项目）
└── Module（模块）
    └── Package（包）
        └── Class（类）
```

但这四个词不属于同一层次：

- **Project**：IDEA 或构建工具管理的整个工程；
- **IDEA Module**：IDEA 工程中的模块，一个 Project 可以有多个 Module；
- **Package**：Java 语言用于组织类、避免命名冲突的包；
- **Class**：Java 中定义数据和行为的类。

一个常见的 Maven / Gradle 项目更接近：

```text
my-project/
├── pom.xml 或 build.gradle
└── src/
    ├── main/
    │   ├── java/com/example/demo/
    │   └── resources/
    └── test/
        └── java/com/example/demo/
```

```java
package com.example.demo;

public class User {
}
```

目录中的 `com/example/demo` 通常对应 `package com.example.demo;`。构建工具、IDEA 的 Module 和 Java 语言的 Package 是不同概念，不能把 IDEA 的默认目录层级当成 Java 语法强制要求。 *已纠正*

Java 9 之后还存在 **Java Module System**，通过 `module-info.java` 声明模块：

```java
module com.example.app {
    requires java.sql;
}
```

Java Module 与 IDEA Module 不是同一个概念。 *已补充*

## 本篇小结
- 字面量是代码中直接写出的值，变量是保存值的命名空间；
- Java 类型分为基本类型和引用类型，`String` 是引用类型；
- `null` 只能赋给引用类型；
- `int` 是最常用的整数类型，`long` 和 `float` 的字面量要注意后缀；
- `Scanner` 负责把 `System.in` 的输入解析为 Java 值；
- Project、IDEA Module、Package、Class 分属工程工具层和 Java 代码层，不能混为一谈。
