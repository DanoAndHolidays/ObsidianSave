# 04 分支与循环

## 学习目标
本篇学习 Java 的流程控制：条件分支、`switch` 多路选择、循环、`break`、`continue`，以及与循环密切相关的一维数组。

---
## 条件分支：`if`
`if` 根据布尔表达式决定是否执行代码。Java 的写法与 JavaScript 相似，但条件表达式必须是 `boolean`，不能直接把数字当作真假值。 *已纠正*

```java
int score = 86;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

建议：

- 条件复杂时拆成有意义的布尔变量；
- 分支体即使只有一行也保留大括号；
- 多个分支互斥时优先使用 `if ... else if ... else`，避免重复判断；
- 不要把 `==` 和 `=` 混淆：前者比较，后者赋值。

```java
boolean adult = age >= 18;
if (adult && hasTicket) {
    enter();
}
```

## 多路分支：`switch`
`switch` 适合根据一个表达式的值匹配多个离散分支。常见可匹配的类型包括整数类型、`char`、字符串和枚举；`long`、`float`、`double` 以及布尔类型不能直接作为传统 `switch` 的选择表达式。

### 传统 `switch`
```java
int day = 2;
String name;

switch (day) {
    case 1:
        name = "星期一";
        break;
    case 2:
        name = "星期二";
        break;
    default:
        name = "其他日期";
}
```

传统写法如果匹配到某个 `case`，执行会继续向下贯穿后续 `case`，除非遇到 `break`、`return` 或 `throw`。这叫 **case 穿透（fall-through）**，有时可以刻意利用，但忘记 `break` 是常见 bug。 *已纠正*

刻意合并多个选项时，可以明确写出多个 `case`：

```java
switch (day) {
    case 6:
    case 7:
        System.out.println("周末");
        break;
    default:
        System.out.println("工作日");
}
```

### 箭头 `switch`
现代 Java 支持箭头标签。箭头分支不会发生传统意义上的贯穿，不需要写 `break`：

```java
String type = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "未知日期";
};
```

箭头 `switch` 表达式还可以返回值；如果使用代码块，需要通过 `yield` 返回结果：

```java
String message = switch (day) {
    case 1 -> "周一";
    default -> {
        String value = "其他";
        yield value;
    }
};
```

箭头写法、逗号分隔的多个标签和 `switch` 表达式需要较新的 Java 版本；项目中应以构建工具配置的 source/release 版本为准。 *已补充*

## 循环
Java 提供三种常用循环：

- `for`：适合循环次数或更新步骤较明确的场景；
- `while`：适合只关心“条件是否继续”的场景；
- `do ... while`：至少执行一次循环体，再判断是否继续。

### `for`
`for` 的执行顺序是：初始化 → 条件判断 → 循环体 → 更新 → 再次判断。

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

这段代码依次输出 `0` 到 `4`。循环变量 `i` 声明在 `for` 初始化部分时，作用域通常只在该 `for` 语句内。

### `while`
```java
int count = 0;
while (count < 5) {
    System.out.println(count);
    count++;
}
```

`while` 可能一次也不执行：如果第一次判断条件就是 `false`，循环体会被跳过。

### `do ... while`
```java
int choice;
do {
    choice = readChoice();
} while (choice < 1 || choice > 3);
```

`do ... while` 会先执行一次循环体，因此适合菜单、输入校验等“至少询问一次”的场景。末尾的分号是语法的一部分。

---
## 循环控制：`break` 与 `continue`
- `break`：立即结束最近的一层循环或 `switch`；
- `continue`：跳过本轮剩余代码，进入下一轮循环判断；
- 嵌套循环中，普通 `break` 和 `continue` 只影响最近的一层。

```java
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue; // 跳过偶数
    }
    if (i > 7) {
        break;    // 结束循环
    }
    System.out.println(i);
}
```

带标签的 `break` / `continue` 可以跳出指定的外层循环，但应谨慎使用；通常把复杂逻辑提取成方法会更清晰。 *已补充*

## 数组
数组用于保存固定长度、同一类型的一组数据。数组本身是引用类型，索引从 `0` 开始，最后一个索引是 `length - 1`。

### 声明与创建
推荐把 `[]` 放在类型后面：

```java
int[] numbers;
int numbers2[]; // 合法，但不推荐作为统一风格
```

数组变量声明后还没有数组对象，必须创建或指向已有数组：

```java
int[] numbers = new int[3];
System.out.println(numbers.length); // 3
```

### 静态初始化
已知元素时可以直接写出内容：

```java
int[] scores = new int[]{90, 85, 100};
int[] ages = {18, 20, 22};
```

`{18, 20, 22}` 这种简写只能在声明并初始化的上下文中使用；单独赋值时需要写 `new int[]{...}`。 *已补充*

### 动态初始化与默认值
只知道长度、不知道具体元素时使用动态初始化：

```java
String[] names = new String[3];
```

数组元素会自动获得对应类型的默认值：

| 类型 | 默认值 |
| --- | --- |
| 整数类型 | `0` |
| 浮点类型 | `0.0` |
| `boolean` | `false` |
| `char` | `\u0000` |
| 引用类型 | `null` |

```java
int[] values = new int[3];
System.out.println(values[0]); // 0

String[] names = new String[3];
System.out.println(names[0]);  // null
```

访问不存在的索引会抛出 `ArrayIndexOutOfBoundsException`，因此遍历时通常使用 `i < array.length`：

```java
for (int i = 0; i < values.length; i++) {
    System.out.println(values[i]);
}
```

增强 `for` 适合只读取元素：

```java
for (int value : values) {
    System.out.println(value);
}
```

增强 `for` 中的 `value` 是当前元素值的局部变量，给它重新赋值不会修改数组元素；需要修改数组时应使用索引，或使用 `Arrays.setAll` 等工具。 *已补充*

---
## 本篇小结
- `if` 处理条件分支，条件必须是 `boolean`；
- 传统 `switch` 要注意 `case` 穿透，箭头 `switch` 不需要 `break`；
- `for`、`while`、`do ... while` 的核心差异是初始化、判断和更新的位置；
- `break` 结束循环，`continue` 跳过本轮；
- 数组长度固定、类型统一、索引从 `0` 开始，遍历条件通常写成 `i < array.length`。
