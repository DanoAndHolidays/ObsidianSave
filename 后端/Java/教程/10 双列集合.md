## HashMap 🔥
[[09 单列集合]]当链表的长度超过8且数组的长度超多64自动的转化为红黑树，这里也是一样的

特点：
- 没有自己的特殊方法，和Map接口一致
- 哈希表结构底层是，依赖hashCode与equals方法来保证健的唯一性，如果建是自定义的对象，就要重写这两方法。如果是值是自定义的，不需要。
- 无序、不重复、无索引
- 插入时，是比较键的值（具有唯一性），而不是值的唯一性

0.75倍的装载因子是什么

这里可以看到实现了equals方法的Student类就能够正确的去覆盖值了：
```java
Map<Student, String> map = new HashMap<>();  
  
map.put(new Student( 12,  "Dano"), "shandong");  
map.put(new Student( 12,  "Dano"), "HeiLongjiang");  
map.put(new Student( 11,  "daozhu"), "shandong");  
map.put(new Student( 13,  "Tom"), "shandong");  
  
map.forEach((s, j)-> System.out.println(s.getName() + " " + s.getAge() + " " + j));
```

线程安全：多个线程同时访问或修改同一份**共享可变数据**时，程序仍然能保证结果正确、状态一致。核心判断：`共享 + 可变 + 并发访问`

才容易产生线程安全问题，例如：
```java
count++;
```

不是原子操作，可以粗略理解为：
```java
读取 count
count + 1
写回 count
```

如果两个线程同时操作，可能都读到旧值，最终发生**更新丢失**。这种结果依赖线程执行时机的问题称为 **Race Condition（竞态条件）**。

`HashMap` **不是线程安全的**。

原因：多个线程同时执行 `put`、扩容 `resize`、修改 `size` 等操作时，没有提供完整的并发同步机制，可能导致数据丢失或状态不一致。常见选择：
```text
单线程 / 不共享 Map
→ HashMap

多线程共享 Map
→ ConcurrentHashMap
```

也可以使用：
```java
Collections.synchronizedMap(new HashMap<>());
```

`Hashtable` 也是线程安全的，但属于较老的方案，现代 Java 通常优先使用 `ConcurrentHashMap`。线程不安全 ≠ 多线程环境下一定不能用。如果每个线程都有自己独立的 `HashMap`，没有共享同一个对象，就不会产生并发冲突。

static class Node<K,V> implements Map.Entry<K,V> {  
    final int hash;  
    final K key;  
    V value;  
    Node<K,V> next;  
  
    Node(int hash, K key, V value, Node<K,V> next) {  
        this.hash = hash;  
        this.key = key;  
        this.value = value;  
        this.next = next;  
    }  
  
    public final K getKey()        { return key; }  
    public final V getValue()      { return value; }  
    public final String toString() { return key + "=" + value; }  
  
    public final int hashCode() {  
        return Objects.hashCode(key) ^ Objects.hashCode(value);  
    }  
  
    public final V setValue(V newValue) {  
        V oldValue = value;  
        value = newValue;  
        return oldValue;  
    }  
  
    public final boolean equals(Object o) {  
        if (o == this)  
            return true;  
  
        return o instanceof Map.Entry<?, ?> e  
                && Objects.equals(key, e.getKey())  
                && Objects.equals(value, e.getValue());  
    }  
}

## TreeMap
没有自己的特殊方法，底层基于红黑树去实现的，增删改查的效率都很好

- 可排序（按照健的值进行排序，自定义的数据结构要实现Comparable接口或者Comparator对象）、不重复、无索引

```java
public class Student implements Comparable<Student> {
	
	... 
	
	@Override  
	public int compareTo(Student o) {  
	    return   o.getAge() - this.getAge();  
	}
}
```

```java
TreeMap<Student, String> map = new TreeMap<>((o1, o2) -> o1.getAge() - o2.getAge());  
  
map.put(new Student(12, "Dano"), "shandong");  
map.put(new Student(12, "Dano"), "HeiLongjiang");  
map.put(new Student(11, "daozhu"), "shandong");  
map.put(new Student(13, "Tom"), "shandong");  
  
map.forEach((s, j) -> System.out.println(s.getName() + " " + s.getAge() + " " + j));  
  
// daozhu 11 shandong
// Dano 12 HeiLongjiang  
// Tom 13 shandong
```

```java
static final class Entry<K,V> implements Map.Entry<K,V> {  
    K key;  
    V value;  
    Entry<K,V> left;  
    Entry<K,V> right;  
    Entry<K,V> parent;  
    boolean color = BLACK;  
  
    /**  
     * Make a new cell with given key, value, and parent, and with     * {@code null} child links, and BLACK color.  
     */    
    Entry(K key, V value, Entry<K,V> parent) {  
        this.key = key;  
        this.value = value;  
        this.parent = parent;  
    }  
  
    /**  
     * Returns the key.     *     * @return the key  
     */    
    public K getKey() {  
        return key;  
    }  
  
    /**  
     * Returns the value associated with the key.     *     * @return the value associated with the key  
     */    
    public V getValue() {  
        return value;  
    }  
  
    /**  
     * Replaces the value currently associated with the key with the given     * value.     *     * @return the value associated with the key before this method was  
     *         called     */   
    public V setValue(V value) {  
        V oldValue = this.value;  
        this.value = value;  
        return oldValue;  
    }  
  
    public boolean equals(Object o) {  
        return o instanceof Map.Entry<?, ?> e  
                && valEquals(key,e.getKey())  
                && valEquals(value,e.getValue());  
    }  
  
    public int hashCode() {  
        int keyHash = (key==null ? 0 : key.hashCode());  
        int valueHash = (value==null ? 0 : value.hashCode());  
        return keyHash ^ valueHash;  
    }  
  
    public String toString() {  
        return key + "=" + value;  
    }  
}
```
