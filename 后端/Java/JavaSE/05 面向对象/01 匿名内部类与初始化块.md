# 01 匿名内部类与初始化块
> Last Format Time：10/6/2026 02:27:25

[[20 有效的括号]]这道题目中有这么一种写法：
```text
Map<Character, Character> mp = new HashMap<>() {{
    put(')', '(');
    put(']', '[');
    put('}', '{');
}};
```

---
## 匿名内部类
```text
new HashMap<>() {
    ...
}
```

表示创建一个继承 `HashMap` 的**匿名内部类**，近似等价于：
```text
class MyMap extends HashMap<Character, Character> {

}

Map<Character, Character> mp = new MyMap();
```

所以这里创建的并不是普通的 `HashMap` 实例，而是：
```text
HashMap 的匿名子类实例
```

---
## 实例初始化块
里面这一层：
```text
{
    put(')', '(');
    put(']', '[');
    put('}', '{');
}
```

是 Java 的**实例初始化块**，它会在对象创建时自动执行。

因此：
```text
put(')', '(');
```

实际上可以理解成：
```text
this.put(')', '(');
```


```text
Map<Character, Character> mp = new HashMap<>() {{
    put(')', '(');
    put(']', '[');
}};
```

大致等价于：
```text
class MyMap extends HashMap<Character, Character> {

    {
        put(')', '(');
        put(']', '[');
    }
}

Map<Character, Character> mp = new MyMap();
```

所以：
```text
new HashMap<>() {{
    ...
}}
```

可以记成：
```text
第一层 {} → 匿名内部类
第二层 {} → 实例初始化块
```

### 为什么工程中不推荐
双大括号初始化虽然代码短，但一般不推荐使用，因为：

- 会额外创建匿名内部类
- 不是真正普通的 `HashMap`
- 某些情况下匿名内部类可能持有外部对象引用
- 可读性较差
- 会产生额外的类

更推荐普通写法：
```text
Map<Character, Character> mp = new HashMap<>();

mp.put(')', '(');
mp.put(']', '[');
mp.put('}', '{');
```

### 固定 Map 可以使用 `Map.of()`
如果 Map 初始化之后不再修改：
```text
Map<Character, Character> mp = Map.of(
    ')', '(',
    ']', '[',
    '}', '{'
);
```

这种写法更简洁，但要注意：
```text
Map.of()
```

创建的是**不可修改 Map**。

例如：
```text
mp.put('>', '<');
```

运行时会抛出：
```text
UnsupportedOperationException
```
