# 03 运算符、表达式
> Last Format Time：9/9/2026 11:32:41

> 运算符作用于操作数，组成表达式；表达式会在编译期确定类型，并在运行期计算出值（或产生副作用）。
>
> 例如，`a + b` 是表达式，`+` 是运算符，`a` 和 `b` 是操作数。 *已修改*

---
## 一、算术运算符与表达式
### 基本算术运算符
| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `+` | 加法；出现 `String` 时也可用于字符串拼接 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b` |
| `%` | 取余（余数） | `a % b` |
| `+x` | 一元正号 | `+x` |
| `-x` | 一元负号 | `-x` |

### 整数除法、浮点除法与取余
当两个操作数都是整数类型时，`/` 执行整数除法，结果会丢弃小数部分：

```java
System.out.println(10 / 2);    // 5
System.out.println(10 / 3);    // 3
System.out.println(10.0 / 3);  // 3.3333333333333335（近似值）
System.out.println(10 % 3);    // 1
```

如果希望得到小数结果，至少要让一个操作数参与浮点运算：

```java
int total = 10;
int count = 3;
double average = (double) total / count; // 3.3333333333333335
```

整数除以零会抛出 `ArithmeticException`；浮点数除以零按照 IEEE 754 规则产生无穷大或 `NaN`：

```java
// int result = 1 / 0;       // ArithmeticException
System.out.println(1.0 / 0);  // Infinity
System.out.println(0.0 / 0);  // NaN
```

`%` 的结果符号与被除数一致：

```java
System.out.println(7 % 3);    // 1
System.out.println(-7 % 3);   // -1
System.out.println(7 % -3);   // 1
```

不要把 `%` 误认为“数学意义上总是非负的模”。如果需要始终得到非负结果，可使用 `Math.floorMod(a, b)`。 *已补充*

### 浮点数精度
二进制浮点数不能精确表示所有十进制小数，因此计算结果可能出现很小的误差：

```java
System.out.println(1.1 + 1.01); // 2.1100000000000003（典型输出）
```

这不是 Java 的加法错误，而是 `float` 和 `double` 使用二进制浮点格式表示数值造成的舍入误差。比较浮点数时，不要轻易使用 `==`，可以比较误差是否小于容差：

```java
double actual = 0.1 + 0.2;
double expected = 0.3;
double epsilon = 1e-10;

boolean closeEnough = Math.abs(actual - expected) < epsilon;
```

涉及金额、计费、精确小数运算时，优先使用 `BigDecimal`，并从字符串构造：

```java
import java.math.BigDecimal;

BigDecimal price = new BigDecimal("0.10");
BigDecimal tax = new BigDecimal("0.20");
BigDecimal total = price.add(tax); // 0.30

boolean equal = total.compareTo(new BigDecimal("0.30")) == 0;
```

`new BigDecimal(0.1)` 会把 `double` 已经存在的二进制误差带入 `BigDecimal`，通常不应这样写。 *已纠正*

### 拆分整数的位数
对非负整数，可以利用整数除法和取余拆分各个数位：

```java
int number = 123;

int ones = number % 10;          // 个位：3
int tens = number / 10 % 10;     // 十位：2
int hundreds = number / 100 % 10; // 百位：1
```

通用规律：

```text
个位：数值 / 10^0 % 10
十位：数值 / 10^1 % 10
百位：数值 / 10^2 % 10
...
```

处理负数时，应先明确业务要求：直接使用 `/` 和 `%` 得到的结果会遵循 Java 的“向零截断”规则；如果要按十进制数学定义处理，可先取绝对值或使用其他明确的规范。 *已补充*

## 二、类型转换与数值提升
### 自动类型提升
在数值表达式中，取值范围较小的类型通常会先提升为取值范围较大的类型，再进行运算。`byte`、`short`、`char` 参与算术运算时，会先提升为 `int`：

```java
byte a = 10;
byte b = 20;

// byte c = a + b; // 编译错误：a + b 的结果类型是 int
int c = a + b;     // 正确
```

可以把常见的提升过程记成：

```text
byte、short、char  ──→ int ──→ long ──→ float ──→ double
```

实际规则还要看表达式中出现的最大类型：

| 表达式 | 常见结果类型 |
| --- | --- |
| `byte + byte` | `int` |
| `byte + short` | `int` |
| `short + char` | `int` |
| `int + int` | `int` |
| `int + long` | `long` |
| `long + float` | `float` |
| `float + double` | `double` |

浮点类型参与运算时，结果类型更大并不意味着一定精确；例如 `int` 转为 `float` 可能丢失低位精度。 *已纠正*

### 字符 `char` 的数值运算
`char` 是无符号的 16 位 UTF-16 代码单元。参与算术运算时会提升为 `int`：

```java
char letter = 'A';

System.out.println((int) letter); // 65
System.out.println(letter + 1);    // 66

char next = (char) (letter + 1);
System.out.println(next);          // B
```

`'A'`、`'a'` 常见的 Unicode/ASCII 兼容码点分别是 65、97，但不要把 Java 的 `char` 简化理解为只能表示 ASCII；它可以表示一个 UTF-16 代码单元。 *已纠正*

### 强制类型转换
当需要把较大类型转换为较小类型时，必须显式强制转换：

```java
double value = 12.8;
int integer = (int) value; // 12，向零截断，不是四舍五入

long large = 200L;
int narrowed = (int) large;
```

整数窄化转换可能溢出，因为只保留目标类型能够容纳的低位：

```java
int value = 200;
byte result = (byte) value;
System.out.println(result); // -56
```

对 `byte`、`short`、`char` 赋值时，值在范围内的编译期常量表达式可以进行常量窄化：

```java
byte a = 10;          // 10 是可表示的编译期常量
final int b = 10;
byte c = b;           // 编译期常量，也允许

int d = 10;
// byte e = d;        // 编译错误：普通变量不能自动窄化
```

不要依赖强制转换“修复”范围问题；强转前应确认数据范围，必要时使用 `Math.toIntExact` 等显式检查方法。 *已补充*

### 复合赋值的隐式转换
```java
byte value = 10;

// value = value + 1; // 编译错误：右侧结果是 int
value += 1;           // 可以编译
```

`value += 1` 可以近似理解为 `value = (byte) (value + 1)`，因此仍然可能溢出：

```java
byte value = 127;
value += 1;
System.out.println(value); // -128
```

复合赋值适合表达“在原变量类型内更新”的意图，但涉及窄类型时要特别留意溢出。 *已修改*

## 三、字符串拼接运算符 `+`
当 `+` 运算的字符串拼接上下文中出现 `String` 时，`+` 会执行字符串拼接，而不是数值加法；连续的 `+` 按从左到右的顺序结合：

```java
System.out.println(1 + 2 + "3"); // "33"
System.out.println("1" + 2 + 3); // "123"
System.out.println(1 + 99 + "年黑马"); // "100年黑马"
```

求值过程如下：

```text
1 + 2 + "3"
→ 3 + "3"
→ "33"

"1" + 2 + 3
→ "12" + 3
→ "123"
```

字符串拼接会把其他操作数转换为字符串；这不会改变原变量本身的类型：

```java
int age = 18;
String message = "age: " + age;

System.out.println(message); // age: 18
System.out.println(age + 1);  // 19，age 仍然是 int
```

`char` 在没有 `String` 时参与数值运算；一旦进入字符串拼接，就按字符内容拼接：

```java
System.out.println('a' + 1);   // 98
System.out.println("a" + 1);   // a1
System.out.println("a" + 'b'); // ab
```

在循环中大量使用 `+` 拼接字符串时，优先考虑 `StringBuilder`：

```java
StringBuilder builder = new StringBuilder();
for (int i = 0; i < 3; i++) {
    builder.append(i).append(' ');
}

String result = builder.toString(); // 0 1 2
```

`null` 参与字符串拼接时会被转换成文本 `"null"`，但这通常可能掩盖业务错误；需要时应提前校验或使用明确的默认值。 *已补充*

## 四、自增、自减运算符
`++` 和 `--` 将变量加一或减一，既可以写在变量前，也可以写在变量后：

```java
int a = 1;
int b = ++a; // 先加一，再取值：a=2，b=2

int c = 1;
int d = c++; // 先取值，再加一：d=1，c=2
```

自增、自减要求操作数是可修改的变量，不能直接对字面量使用。复杂表达式中混用前置和后置形式会降低可读性，实际代码应优先拆成多行。 *已补充*

## 五、赋值运算符
### 基本赋值与复合赋值
```java
int value = 10;

value = 20;
value += 5;  // value = value + 5
value -= 3;  // value = value - 3
value *= 2;  // value = value * 2
value /= 4;  // value = value / 4
value %= 3;  // value = value % 3
```

常见的复合赋值运算符还有：

```java
&=  |=  ^=  <<=  >>=  >>>=
```

复合赋值的左操作数只求值一次，并包含必要的隐式转换。例如 `x += y` 在类型转换上近似于 `x = (T) (x + y)`，但不能把它机械替换为等价的字符串或副作用表达式。 *已补充*

### 赋值表达式本身有值
赋值表达式的值是赋值后的值，因此可以连续赋值，但生产代码不建议为了省行而牺牲可读性：

```java
int a;
int b;
a = b = 10;
```

## 六、关系运算符与相等运算符
### 数值比较
```java
int age = 18;

age < 18
age <= 18
age > 18
age >= 18
age == 18
age != 18
```

这些表达式的结果类型都是 `boolean`。

### `==` 的常见陷阱
对于基本类型，`==` 比较数值；对于引用类型，`==` 比较是否指向同一个对象，而不是字符串内容：

```java
String left = new String("java");
String right = new String("java");

System.out.println(left == right);       // false，两个对象不是同一个
System.out.println(left.equals(right));  // true，内容相同
```

比较字符串内容应使用 `equals`，并注意避免对可能为 `null` 的变量直接调用方法：

```java
if ("java".equals(input)) {
    // 即使 input 为 null，也不会抛出 NullPointerException
}
```

`String`、包装类型等引用类型的相等比较应根据业务语义选择 `equals` 或 `Objects.equals`，不要只凭 `==` 判断内容。 *已补充*

### `instanceof`
`instanceof` 判断对象是否是某个类型的实例，结果也是 `boolean`；对象为 `null` 时结果为 `false`：

```java
Object value = "Java";
if (value instanceof String text) {
    System.out.println(text.length());
}
```

上面的模式变量写法适用于支持模式匹配的现代 Java 版本；如果项目版本较旧，可使用传统的 `instanceof` 加强制转换。 *已补充*

## 七、逻辑运算符与短路求值
### 逻辑运算符
Java 不存在 JavaScript 中的 truthy/falsy 自动转换。`&&`、`||`、`!` 的操作数必须是 `boolean`：

```java
boolean loggedIn = true;
boolean hasPermission = false;

boolean allowed = loggedIn && hasPermission;
boolean visible = loggedIn || hasPermission;
boolean hidden = !loggedIn;

// if (1) { } // 编译错误：int 不是 boolean
```

如果要把数值条件用于 `if`，必须明确比较：

```java
int count = 1;
if (count != 0) {
    System.out.println("count 非零");
}
```

### `&&`、`||` 会短路
短路意味着：当左侧已经足以决定结果时，右侧不再求值：

```java
if (user != null && user.isActive()) {
    // user 不为 null 时才调用 isActive()
}

if (cacheHit || loadFromNetwork()) {
    // cacheHit 为 true 时不会调用 loadFromNetwork()
}
```

因此，带有空值保护、边界保护或昂贵计算时，通常应优先使用 `&&` 和 `||`。 *已补充*

### `&`、`|`、`^` 在 `boolean` 上不短路
当操作数是 `boolean` 时，`&`、`|`、`^` 也可以表示逻辑运算，但两侧都会求值：

```java
boolean result1 = false & check(); // check() 仍会执行
boolean result2 = true | check();  // check() 仍会执行
boolean result3 = true ^ false;    // true
```

只有在确实需要两侧都执行时才使用 boolean 上的 `&` 或 `|`；普通条件判断优先使用短路运算符。 *已修改*

## 八、位运算
位运算把整数按二进制的每一位分别处理。图示中的“0 为 false、1 为 true”只能理解为单个位上的示意，不能理解成 Java 会把整数自动转换为 `boolean`。 *已纠正*

### 按位与、或、异或、取反
```text
5  = 0101
3  = 0011

5 & 3 = 0001 = 1   // 对应位都为 1 才为 1
5 | 3 = 0111 = 7   // 对应位有一个为 1 就为 1
5 ^ 3 = 0110 = 6   // 对应位不同才为 1
~5    = ...1010    // 每一位取反
```

Java 示例：

```java
System.out.println(5 & 3);  // 1
System.out.println(5 | 3);  // 7
System.out.println(5 ^ 3);  // 6
System.out.println(~5);     // -6
```

`~x` 等价于 `-x - 1`，因为有符号整数使用二进制补码表示。

位运算常用于掩码、权限标志、状态位和底层协议字段：

```java
final int READ = 1;   // 0001
final int WRITE = 2;  // 0010

int permissions = READ | WRITE;
boolean canWrite = (permissions & WRITE) != 0;
```

### 左移、带符号右移、无符号右移
| 运算符 | 含义 | 高位/低位处理 |
| --- | --- | --- |
| `<<` | 左移 | 向左移动，右侧补 `0` |
| `>>` | 带符号右移 | 向右移动，左侧补符号位 |
| `>>>` | 无符号右移 | 向右移动，左侧补 `0` |

```java
int value = 8; // 000...1000

System.out.println(value << 1);  // 16
System.out.println(value >> 1);  // 4
System.out.println(value >>> 1); // 4

int negative = -8;
System.out.println(negative >> 1);  // -4，补 1
System.out.println(negative >>> 1); // 2147483644，补 0
```

左移在不溢出的前提下近似于乘以 `2^n`；右移带符号时近似于向下取整的除以 `2^n`。移位可能溢出，不能把它当成无条件安全的乘除法。 *已补充*

移位距离有一个容易忽略的规则：对 `int`，实际只使用右操作数的低 5 位，因此距离相当于对 `31` 取掩码；对 `long`，只使用低 6 位，相当于对 `63` 取掩码：

```java
System.out.println(1 << 32); // 与 1 << 0 相同，结果为 1
```

### 原码、反码与补码
现代 Java 有符号整数按二进制补码参与运算。以 8 位为例：

- 正数的原码、反码、补码相同。
- 负数的补码等于其绝对值的二进制按位取反后再加 `1`。
- 8 位 `byte` 的范围是 `-128` 到 `127`，因为补码只有一个零，最高位参与表示符号和数值。

```text
  1  的补码：0000 0001
 -1  的补码：1111 1111
-128  的补码：1000 0000
 127  的补码：0111 1111
```

原码和反码有助于理解历史上的表示方式，但编写 Java 代码时应重点掌握补码、溢出和移位行为。对 `byte`、`short`、`int`、`long` 的算术运算，仍应先考虑 Java 的数值提升规则。 *已修改*

## 九、条件运算符（三元运算符）
条件运算符的形式是 `条件 ? 值1 : 值2`：

```java
int score = 85;
String result = score >= 60 ? "及格" : "不及格";
```

它只会计算被选中的分支，因此可以避免无意义或有副作用的另一侧计算。但嵌套三元表达式容易降低可读性，复杂条件应改用 `if/else`。

## 十、运算符优先级与求值顺序
优先级只决定如何分组，不等于所有操作数都按“从左到右立即执行”。涉及副作用时，仍应理解 Java 的求值规则；不确定时直接加括号。

从高到低的常见顺序如下：

| 优先级 | 运算符 |
| --- | --- |
| 最高 | 后缀：`x++`、`x--`、方法调用 `()`、数组访问 `[]`、成员访问 `.` |
|  | 一元：`++x`、`--x`、`+`、`-`、`!`、`~`、强制转换 |
|  | 乘除模：`*`、`/`、`%` |
|  | 加减：`+`、`-` |
|  | 移位：`<<`、`>>`、`>>>` |
|  | 关系：`<`、`<=`、`>`、`>=`、`instanceof` |
|  | 相等：`==`、`!=` |
|  | 按位与：`&` |
|  | 按位异或：`^` |
|  | 按位或：`|` |
|  | 短路与：`&&` |
|  | 短路或：`||` |
|  | 三元：`? :` |
|  | 赋值：`=`、`+=`、`-=`、`*=`、`/=`、`%=` 等 |
| 最低 | Lambda：`->` |

例如：

```java
int result = 1 + 2 * 3;      // 7
boolean ok = a > 0 && b > 0;
int value = condition ? 1 : 2;
```

团队代码中建议用括号明确意图，而不是依赖读者记忆优先级：

```java
int result = (a + b) * c;
boolean valid = (age >= 18) && hasPermission;
```

## 十一、运算符实践清单
1. 涉及金额或精确小数时，使用 `BigDecimal`，不要用 `double` 直接累计。
2. 整数除法前先确认是否需要小数；需要时显式提升其中一个操作数。
3. `byte`、`short`、`char` 参与算术运算后通常是 `int`，赋值回窄类型前检查范围。
4. 数值比较和字符串内容比较要区分：引用类型通常使用 `equals` 或 `Objects.equals`。
5. 条件判断使用真正的 `boolean`；Java 没有 JavaScript 的 truthy/falsy。
6. 可能为 `null` 或包含昂贵计算时，优先使用 `&&`、`||` 的短路特性。
7. 位运算用于掩码、状态位和底层数据处理时，明确写出掩码含义并补充注释。
8. 对复杂表达式加括号；不要在同一行混用多个自增、自减和赋值副作用。
9. 看到强制类型转换、整数溢出和浮点比较时，优先问自己：范围、精度和边界是否经过验证？ *已补充*
