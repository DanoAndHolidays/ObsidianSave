## 可执行学习路线
### 阶段一：语言基础与面向对象（1–2 周）
1. 补完接口、继承、多态、抽象类、封装和组合。
2. 完成集合、异常、泛型、Lambda、Stream、Optional、日期时间和注解基础。
3. 每天至少写 3 个小练习；每个主题至少保留一个可运行示例和一条自己的总结。
4. 阶段项目：命令行图书管理系统或记账系统。

**阶段验收：** 能从零创建 Maven 项目，使用面向对象设计拆分业务，处理异常，写 JUnit 5 测试，并解释关键 API 的适用场景。 *已补充*

### 阶段二：Java 核心与运行时（2–3 周）
1. 深入集合：哈希、扩容、排序、比较器、不可变集合和并发集合的使用边界。
2. 深入 I/O：文件、字节流、字符流、缓冲、序列化的风险和 NIO 基础。
3. 并发编程：线程生命周期、线程安全、`synchronized`、`volatile`、锁、线程池、`Future`、`CompletableFuture`、并发容器和常见死锁场景。
4. JVM 基础：堆、栈、方法区、垃圾回收、类加载、内存溢出与常用诊断工具。
5. 网络基础：HTTP、TCP/IP 基本概念、JSON、REST 资源设计、状态码和幂等性。

**阶段验收：** 能写一个线程安全的任务处理器，使用线程池执行任务，处理超时和异常，并能根据日志和线程转储定位基本问题。 *已补充*

### 阶段三：数据库与后端基础（2–3 周）
1. SQL：查询、连接、聚合、子查询、事务、索引、约束和分页。
2. 数据库设计：实体关系、主键、范式与反范式、软删除、审计字段和数据一致性。
3. JDBC：连接、预编译语句、事务边界、资源释放和 SQL 注入防护。
4. Redis 基础：缓存、过期、穿透、击穿、雪崩、分布式锁的适用边界。
5. API 设计：请求校验、统一响应、错误码、分页、日志、鉴权和接口文档。

**阶段验收：** 能为一个业务设计表结构和索引，写出带事务的增删改查服务，并说明缓存与数据库不一致时的处理策略。 *已补充*

### 阶段四：Spring 与 Spring Boot（3–4 周）
不要跳过 Spring 核心概念；Spring Boot 是工程启动和自动配置方式，不会替代 Java 基础、HTTP、SQL 或面向对象设计。 *已纠正*

1. Spring 核心：IoC、DI、Bean 生命周期、作用域、配置、组件扫描和面向切面编程的基本概念。
2. Spring Boot：项目结构、自动配置、配置文件、Profile、日志、Actuator 和启动流程。
3. Web：Controller、路由、参数绑定、校验、全局异常处理、文件上传、CORS 和 REST API。
4. 数据访问：Spring JDBC 或 MyBatis；理解 ORM 基本思想后再学习 JPA / Hibernate。
5. 事务：`@Transactional` 的代理边界、自调用失效、传播行为、隔离级别和回滚规则。
6. 安全：Spring Security、密码哈希、Session/JWT、认证与授权、最小权限和常见 Web 安全风险。
7. 文档与测试：OpenAPI、MockMvc、集成测试、Testcontainers 的基本使用。

**第一个 Spring Boot 项目：** 用户与任务管理 REST API。

- 用户注册、登录、密码安全存储。
- 任务的创建、查询、更新、删除和分页。
- 请求参数校验、统一错误响应和全局异常处理。
- MySQL 持久化，Redis 缓存一个明确的读多写少场景。
- JUnit 5 + MockMvc 测试核心接口。
- README 中写清启动方式、配置项、接口示例、数据库初始化和测试命令。

**阶段验收：** 能独立从空目录创建、运行、测试和打包一个 Spring Boot REST API，并能说明每个分层和关键注解的作用。 *已补充*

### 阶段五：工程实践与生产能力（持续迭代）
1. 工程结构：模块边界、分层、DTO / VO / Entity、依赖倒置、配置与密钥分离。
2. 可观测性：结构化日志、请求链路标识、指标、健康检查、错误告警和审计日志。
3. 质量保障：代码审查、静态检查、格式化、测试覆盖率、契约测试和回归测试。
4. 构建与部署：Maven 构建、Docker、环境变量、Linux 基础、反向代理和 HTTPS 基础。
5. CI/CD：自动构建、测试、镜像发布、分环境配置和回滚策略。
6. 性能与稳定性：慢 SQL、连接池、缓存命中率、线程池参数、限流、重试、熔断和降级。
7. 分布式基础：消息队列、最终一致性、幂等、分布式事务取舍、服务拆分和配置中心；先理解问题，再引入组件。 *已补充*
